# 押韵与韵式（Rhyme）

> **押韵不是装饰，是结构。**
> 它告诉耳朵"往哪走、什么时候停"——歌是唱给耳朵听的，耳朵看不见分行。
> （Pattison《Essential Guide to Rhyming》第一章："Songs are made for ears, not eyes."）

★ **本 skill 的核心不是"怎么找到韵脚"，是"选哪一种韵"。**
找韵脚是机械劳动；**用韵是创作**。

## 1. 押韵在做的三件事

| 它做什么 | 怎么用 |
|---|---|
| **1. 给耳朵画路线图** | 韵脚标出乐句边界，听众靠它知道"这句完了"。诗可以靠分行，词只能靠声音 |
| **2. 把聚光灯打在某个词上** | ★ 韵脚位置是 **HOT SPOT**：后面有语法停顿、常伴音乐休止、旋律与和声在提示"要来了"、声音又和前面某个词像——四重注意力叠在一个字上 |
| **3. 连接两个意思** | 声音连上的同时意思也连上，Pattison 称 **double whammy** |

★★ **第 2 条推出本 skill 最硬的一条纪律**：

> **韵脚位置不许放平庸的词。**
> 那是全曲注意力最集中的几个位置，用掉一个就少一个。

**自检动作（HOT SPOT 测试）**：
**把整首词的韵脚字单独抄成一列，只读这一列。**
读得出这首歌在讲什么 → 韵脚位置用对了；读出来是一串虚词 → 位置全浪费了。
（Pattison 用 "It Was a Very Good Year" 演示：光看韵脚就几乎是完整故事线。）

**失效条件**：说唱与某些电子曲风里韵脚极密、且大量在行内，此时这个测试只对句末韵有效 → `lw-rap`。

## 2. ★ 稳定度尺度：韵型决定"收"到什么程度

**这是本 skill 的地基。**

> **韵和和弦一样有稳定度。**
> 如果规定每段都必须落在主和弦上，音乐就没有渴望、没有含糊了。
> 韵也一样：**越接近完美韵越收束，越远越悬着。**

Pattison 本人不爱用 "perfect rhyme" 这个叫法，因为 "perfect" 听起来像"更好"；
他更愿意叫 **fully resolved rhyme（完全解决的韵）**——**这是描述，不是褒奖。**

### 2.1 尺度表

三条判据永远是同一组：**① 元音是否相同 ② 元音后的辅音关系 ③ 元音前是否不同**。

| 韵型 | ① 元音 | ② 元音后辅音 | ③ 起音 | 稳定度 | 用来支持什么 |
|---|---|---|---|---|---|
| **Identity 同音** | 同 | 同 | **也相同** | ★ **不是韵** | 耳朵只听见重复（`fuse` / `confuse`），没有张力解决 |
| **Perfect 完美韵** | 同 | 同 | 不同 | ●●●●● 全收 | 事实、确定、承诺 |
| **Family 家族韵** | 同 | **同一语音家族** | 不同 | ●●●●○ | 完美韵的替身，门虚掩着 |
| **Additive 加音韵** | 同 | 一边**多**一个（或多个）辅音 | 不同 | ●●●○○ | 加得越少越接近完美韵 |
| **Subtractive 减音韵** | 同 | 一边**少**一个辅音 | 不同 | ●●●○○ | 同上，反向操作 |
| **Assonance 元音韵** | 同 | **互不相关** | 不同 | ●●○○○ | 悬着、漂、没说完 |
| **Consonance 辅音韵** | **不同** | **相同** | 不同 | ●○○○○ 最不稳 | 放不下、悲伤、回头看 |
| **Partial 部分韵** | 阳性音节 ↔ 阴性词的**重读音节**，弱音节不管 | | | 专用 | ★ **专门用来阻止闭合** |

★ **`Identity` 那一行是个陷阱**：`peace` / `piece`、`lease` / `police` 起音相同，
听感是重复不是押韵。**押韵要"从不同走向相同"**，起音必须不同。

★ **另一条轴（与上表正交）**——重音落在哪：

| | 定义 | 例 |
|---|---|---|
| **Masculine 阳性韵** | 单音节词，或**以重读音节结尾** | command / land / understand / expand |
| **Feminine 阴性韵** | **以非重读音节结尾**，通常是双音节韵 | commanding / landing / understanding |
| **Mosaic 马赛克韵** | 用不同单词的音节拼出来的韵 | commander / understand her；lonely / hold me |

- **阴性韵的张力解决仍然发生在重读音节上**，末尾那个弱音节通常是 Identity，把"解决感"再拖长一点
- ★ 所以**阴性韵比同类型的阳性韵更稳**——多出来的那个音节给了额外的解决
- **一个词只能是阳性或阴性，不可能兼有**
- **次重音会翻车**：`appreciate` 最后一个音节比前一个强，**不能当阴性韵**。要么当单音节阳性韵（/ fate / relate），要么当三音节韵（/ the quiche he ate）——★ **后者只适合写喜剧**

### 2.2 为什么不完美的韵在歌里成立

**因为词是唱的，不是念的。**
唱的时候元音被拉长、被夸张，辅音被压扁。
**韵的本质是元音的连接**——元音一被放大，辅音上的差别就没那么要紧了。

**自检动作**：★ **检查一个韵脚时必须唱出来，不能只看。**
"NEVER STOP LISTENING… TRUST YOUR EARS.（但检查的时候一定要唱。）"

**失效条件**：
- **念白段、rap 的清晰吐字段落** → 元音没被拉长，家族韵会露馅
- **音符很短的快速段落** → 加音韵里多出来的那个辅音会变得刺耳（音符越长，多出的辅音越不明显）

## 3. ★ 用韵型控制段落的开合

**这是本 skill 里最值钱的一节。**

### 3.1 韵式里的两个位置

一个 abab 段落里，**四个位置的功能不一样**：

```
blush  a          第 3 行 = 推进位（Pattison 类比属功能 V）
skin   b          第 4 行 = 解决位（类比主功能 I）
rush   a   ← 推进位
sin    b   ← 解决位
```

`a b a` 建立了一个序列，耳朵开始等第二个 `b`。
**第 3 行推得越狠，第 4 行砸下去越响。**

**语料实测**（国语非说唱 n=487，分层样本逐首读）：**换韵 51%**，一韵到底约四成，不押 9%；说唱换韵 75%、不押 12%（n=100）；粤语换韵 33%（n=36）。
换韵在华语流行里是多数做法，"一韵到底"是选择而非默认，下面四种组合都有人用。

### 3.2 四种组合（同一段词，只换韵型）

| 推进位（a） | 解决位（b） | 听感 |
|---|---|---|
| 完美韵 `rush` | 完美韵 `sin` | **推得最狠，落得最实**。门砰一声关上 |
| **家族韵** `touch` | 完美韵 `sin` | 推力轻一点，落点仍然实 |
| 完美韵 `rush` | **家族韵** `touch` | ★ 推力很强，**落在软一点的地方——门留了一条缝** |
| **元音韵** `drift` | 完美韵 `rush` | 推进位几乎不推，整段变成 `xaxa` 的感觉，很轻 |
| 完美韵 `rush` | **元音韵** `drift` | ★★ **强推力落在软面上，从侧面漏出去**——稳定的 abab 突然收不了尾 |
| 家族韵 `touch` | 元音韵 `drift` | **整段飘起来**，梦一样 |
| 辅音韵 `dawn` | 家族韵 `touch` | 推进位几乎不推，但**比完全不押还是多一点向前的压力** |
| 家族韵 `touch` | **辅音韵** `dawn` | ★ 门大开着，**`dawn` 在发抖、回头看 `skin`**——含泪往前走。这是"悲伤" |

★★ **结论**：
**韵式不用改，只换韵型，情绪就换了。**
这是在不破坏段落结构（主歌一二段旋律必须一样）的前提下，
**唯一能让两段情绪不同的手段。**

### 3.3 主歌与副歌的用韵差别

| 段落 | 常见做法 | 原因 |
|---|---|---|
| **副歌** | 韵脚**密、连续、偏完美韵** | 副歌要"冲出起跑线"，连续韵（一行接一行）是韵能跑的最快速度 |
| **主歌** | 韵脚**疏、间隔大** | 悠闲的步子配得上铺陈；等韵开始把后几句和前几句连起来时，压力自然把段落往前推 |
| **主歌 1 ⇄ 主歌 2 情绪不同时** | ★ **韵式不动，换韵型**（见 §3.2） | 旋律结构必须一样，改韵式会露馅 |
| **过门／pre-chorus 结尾** | 用**远韵或不押**把门打开 | 让它别停下来，直接推进副歌 |

**实例（Pattison 分析 Randy Newman "Feels Like Home"）**：
第一段 pre-chorus 用 `long` / `done`（鼻音 ng 与 n，最远的家族/辅音关系）——**门开着，是渴望与不确定**；
第二段 pre-chorus 用 `touch` / `much`（完美韵）——**门砰地关上，这就是稳定**。
把第一段改成完美韵 `long` / `strong` 之后，意思几乎没变，但全曲从"不稳/不稳/稳"变成"不稳/稳/稳"，
**后半首听起来像重复而不像成长。**

★ **这个例子是本节的标准示范**：**同样的意思，换一个韵脚，运动（motion）和情绪（e-motion）全变了。**

### 3.4 韵不够收时的补救

如果内容上非要用一个不稳的韵，但结构上又需要收住：

1. **接受它**——"在这个点上我能忍受韵对结构的影响被压住"
2. ★ **用音乐补**：**把那个音延长**，让元音的连接被听得更清楚；或用旋律／和声补上那份闭合
   （→ 库一 `mc-melody`、`mc-harmony`）

**失效条件**：★ **补救只对"元音相同"的那几类韵（家族／加减音／元音韵）有效。**
辅音韵元音本来就不同，拉长音符只会让不同更明显。

### 3.5 段落稳定性排序：行数 × 韵式（Pattison p0015–0017）

§3.2 说的是换韵型，这一节是**换韵式和行数**：同样几行，哪种排法收得住、哪种往前冲。A 表示押韵行，X 表示不押的行，字母不同表示不同韵。判据只有两条：**匹配的行让段落停下，不匹配的行让它往前倾**；**先长后短比先短后长更不稳**，因为长行经过时已经"匹配"过短行的长度（p0015）。

**二行**（从稳到不稳，p0015）：等长且押韵 → 等长不押 → 不等长押韵 → 不等长不押。等长不押已经足以刹住，押韵只是把门关得更响。

**三行**（p0016）：**AAA → ABB → XXX → AAB → ABA**。
- AAA 最稳但仍"略欠完整"，第三行讲前两行的结果时最像收住；John Mayer 靠重复标题把 AAA 用成了往前的悬念。
- ABB 首行长则期待第四行来配 A，首行短则近乎独立、像认命。
- XXX 是漂着，不推也不停。
- ABA 最不稳，它是四行 common meter 的四分之三，强烈要第四行。

**四行**（p0016–0017）：稳定组 **AAAA → AABB → ABAB → XAXA → ABAA → XXAA → XAAA → AABA → ABBA**；不稳定组 **AAAX、AXAX、XAAX、XXXX**。
- ABBA 稳，常用于副歌。
- AAAX：三个 A 让人等第四个 A，不给就一直想要（目标原则），X 行正是**放标题的位置**；AXAX 推得最狠，也适合放标题。
- 第二、四行等长会更稳；末行比上一行长，比它短的版本稳。

**五行**（p0017）：奇数行总有一行没伴，靠**意外闭合**（unexpected closure）收住，最适合主歌。
- 只有一组匹配：**AAAAA → XAAAA → XXAAA → XAXAA → XXXAA → XXAXA → AAAAX**；以 X 结尾的五行最不稳。★ 第五行是**重复第一行标题的绝佳位置**。
- 两组匹配、前两行不同：**ABABB → ABAAB → ABBAA → ABBAB → ABAAA → ABABA**；前两行相同：**AABBA → AABBB → AAABB**。
- 三种韵：**ABCAC → ABCBC → ABCBB → ABCAA**。

**用法**：先定这一段要停还是要冲（副歌多半要停，主歌末尾与预副歌要冲），再从对应行数的表里往稳或不稳的那头选；选完用 §3.2 换韵型微调力度。中文四行以 AABA、ABAB 最常见（→ `lw-chinese-style`），这张表给的是**偏离常见时会发生什么**。

## 4. 韵式

### 4.1 常见韵式的性格

| 韵式 | 性格 | 什么时候用 |
|---|---|---|
| **AABB** | ★ **碎片化**。第一个对句一结束就"摔门"，完全停住，再重新发动 | 两个并列的意思，一个给 aa 一个给 bb |
| **ABAB** | ★ **贯穿式（through-written）**。系统和意思一直在动 | 一个意思要连续流下去 |
| **ABCB / XAXA** | 只有偶数行押，奇数行放空 | 步子最松，叙事型的词常用 |
| **连续韵（aaa / ccc）** | ★ **加速**，建立压力 | 情绪在段落后半变激烈时 |
| **越写越密** | 前两段隔行押，第三段改 ABAB | 给第三段额外的分量 |

★ **一句话规则**：
**要意思流动，就把韵式写通（through-write）；要意思分块，就把它打碎（fragment）。**

★ **连续完美韵的对句为什么让歌"显得长"**：每两行就得停一次、再起步一次，
一路是停止标志。

### 4.2 三种闭合

一个韵系统建立了预期之后，最后一行怎么落，只有三种：

| 闭合 | 定义 | 效果 |
|---|---|---|
| **Expected 预期内** | 落在系统预告的那个韵上 | 正常收束 |
| **Deceptive 欺骗性** | ★ 用了**系统里已经出现过**的声音，但不是耳朵在等的那一个 | 收了，但收错地方 |
| **Unexpected 意外** | 预期已经满足之后又多押一次；或系统根本没建立清晰预期 | ★ **毫无征兆**，真正的惊喜 |

★ **用法**：**把最重要或最意外的意思，放在结构本身也出意外的那个位置。**
意思和结构一起出意外 → 这就是 prosody。

★ **一点含糊是好东西**。"Do not be upset by ambiguity. A little bit is a very useful thing."
（Pattison《Lyric Form and Structure》p0047）

### 4.3 行数奇偶与"还没说完"

| | 效果 |
|---|---|
| **偶数句** | 平衡，**运动停止**。最后一句是"平衡位"，聚光灯打在那儿 |
| **奇数句** | ★ **不平衡**，产生**前进感**——耳朵在等那个没来的平衡位，压力就是这么建立的 |

★ **奇数句最适合放在主歌通向副歌的位置**：让它推不动就往前倒。
（Pattison《Lyric Form and Structure》p0011–p0012）

**失效条件**：
- 两个短句加起来顶一个长句时，**句数虽奇结构却是平的**（如五行打油诗式的主歌）
- ★ **句数与句长归 `lw-structure`**，本节只说它与韵的配合

**自检动作**：韵式定下来之后，**先把下一段的意思拿过来套一遍**。
这个韵式是要被重复的——如果第二段的意思是"放松下来了"，而韵式在段落后半加速建压，
两者就打架。三条出路：改韵式折中／换一个更配的第二段意思／**把它挪去做 bridge**。

## 5. 内韵与多音节韵

### 5.1 内韵（Internal Rhyme）

**定义**：发生在句子内部而不是句末的韵。

| 性质 | 说明 |
|---|---|
| **功能** | 连接意思、**制造加速**、造出"迷你 HOT SPOT" |
| ★ **局限** | **只有局部效果**。它**不影响乐句结构**，**也不需要在平行段落里对上** |
| **对称放置** | 连续几行的**同一个节奏位置**上押 → 规整的加速 |
| **非对称放置** | ★ 放在**不同的节奏位置** → 失衡感 |

★ **这是内韵与尾韵最大的区别**：
**尾韵是承诺（主歌 1 押了，主歌 2 就得押），内韵不是。**
"放进这一段，让它干完活，然后就可以忘了它。"

**失效条件**：
- **同一个声音在一行里押太多次会产生人工感（artifice）** → 这在喜剧和讽刺里是优点，在抒情里是灾难
- ★ **说唱里内韵是主结构不是装饰** → `lw-rap`

### 5.2 多音节韵

- **阴性韵（双音节）比阳性韵更强**，因为非重读音节的延长解决提供了更强的连接
- **马赛克韵**把一个多音节词和几个短词拼起来押：`lonely` / `hold me`；`business` / `tonic fizzless`
- ★ **口语省音能救急**：非正式语气里把 `-ing` 的 g 去掉（`sailing` → `sailin'`），就能和别的词凑成马赛克韵。乡村与嘻哈里很常见
- ★ **马赛克韵必须有一个"链接意思"撑着**：`fizzless` 之所以成立，是因为前面有 `drink my tonic`。**没有那个链接，拼出来的韵就只是耍小聪明**

**自检动作**：把马赛克韵那一行**单独念给别人听**，问他是否需要解释。要解释 → 拆掉。

## 6. ★ 意外度：为什么"第一个想到的韵脚"是 AI 指纹

### 6.1 症状

**AI 写的词（和写快了的人写的词）押韵都太顺。**
原因很简单：**最容易想到的韵脚，就是被用得最多的韵脚。**

| 类别 | 例 |
|---|---|
| **空洞韵脚（empty rhymes）** | `me` / `do` / `be` / `you` / `know` / `so` |
| **陈词滥调韵（cliché rhymes）** | `fire` / `desire`；`love` / `above`；`moon` / `June`；`hand` / `heart`；`you` / `do` / `blue` / `through` / `new`；`regret` / `forget` |
| **一被写出来就会带出固定下一句的词** | `dreams` → "coming apart at the seams" |

"These pairs all cause sleeping sickness."（Pattison《Essential Guide to Rhyming》第二章）

★ **更麻烦的一层**：**陈词滥调韵会逼你说出你本来不想说的话**
（《Lyrics: Writing Better Words for Your Songs》p0055）。
**韵脚选早了，意思就被韵脚拖着走。**

### 6.2 为什么英语特别难

**英语是"贫韵语言（rhyme-poor language）"。**
意大利语、法语、西班牙语靠系统的词尾变化表示语法功能，词尾种类少，韵就多；
英语只有 `-ing` 和 `-ly` 两种次要词尾，**词尾五花八门，能押上的就少**——
于是仅有的那些韵被用到烂。

### 6.3 怎么把候选扩大

★ **先讲顺序**：**别先写句子再找韵。**
Pattison 的比喻——**找韵脚像交朋友，得去可能有同类的地方找**，
不是写完一句再回头硬凑。

**工作表三步（Pattison 的 worksheet）**：

1. **把这首词要说的事聚焦清楚**（→ `lw-song-intent` 的四项）
2. **列出配得上这个意思的词**，写在纸中央，编号框起来
   - ★ **主要找阳性词**（单音节或重音在末的），**并且刻意挑不同元音的词**
3. **逐个去查韵**，★ **只抄下与这首词的意思对得上的韵脚**

**第 3 步的筛除规则**：

| 筛掉 | 为什么 |
|---|---|
| **及物动词** | 放在韵脚位置需要宾语，句子会瘸（`erase`、`desert`、`strafe`）。★ **救法：加 `-ed` 变被动**——"As if my heart could be erased" 就顺了，代价是主动语态更有力 |
| **陈词滥调** | 见 §6.1 |
| **韵脚太少的词** | `safe`、`business` 这种，早点换掉比后面硬扛便宜 |
| **行尾难押的经典麻烦词** | `love`、`world`、`field`、`heart`、`room`、`moon` |

★ **改词形也算一招**：`scared` 改成 `scare`，能查到的韵立刻多一圈。

**然后用韵型扩容**（详细搜索顺序见 [reference.md](reference.md)）：

| 手段 | 扩容倍数 |
|---|---|
| **家族韵**（换成语音上的亲戚辅音） | ★ 约 **5 倍**于完美韵 |
| 家族韵（摩擦音一类） | 至少 **4 倍** |
| 加音韵 / 减音韵 | 再加一层 |
| 元音韵 | **最宽的一次搜索**——凡是这个元音开头的都能看 |

### 6.4 判断一个韵脚"意外又觉得对"

| # | 判据 |
|---|---|
| **1** | ★ **double whammy**：**声音连上了，意思也连上了**。只连声音是凑韵，只连意思不是韵 |
| **2** | **它不是从固定搭配里拿出来的**。`daze` 一旦离开 `haze`，立刻新鲜 |
| **3** | ★ **它把词往一个你原本没想到的方向带**。"Rhymes are suggestive"——好韵脚会提示下一个意思（`scold` / `hold` 暗示吵完架之后的和解；`break` / `mistake` 暗示打碎了妈妈最喜欢的那盏灯） |
| **4** | **不需要为它扭曲语言**。为了押韵把 `knew` 写成 `knowed`、把 `you` 写成 `thee`——读者听得出来 |

★ **第 3 条是正循环**：**查韵不只是找词，它本身能生出新的意思。**

**自检动作**：
- 把全曲韵脚抄成一列，**圈出其中属于 §6.1 三类的**。★ 圈出来超过一半 → 重做工作表
- 每一对韵脚问一句：**"这两个词除了声音像，还有关系吗？"**

**失效条件**：
- **喜剧、讽刺、抗议歌**里，明显的、反复的、甚至硬凑的韵是**手段不是毛病**——人工感正是笑点与刺
- **儿歌、口号型副歌**要的就是最顺的那个韵
- ★ **说唱另算** → `lw-rap`

## 7. 故意不押

### 7.1 先说反面

★ **"干脆不押"通常是逃避。**
很多人会经过一个"我不要押韵"的阶段，因为押韵难、容易显得做作。
但**诗可以靠视觉（分行、留白），词只能靠听觉**——
拿掉韵，等于把听众的路标全撤了。

**所以：破韵是局部手段，不是整体策略。**

### 7.2 该破韵的位置

| 情形 | 怎么做 |
|---|---|
| **这一段的意思本来就是悬着的** | 用远韵或不押。**用不稳定支持不稳定的意思** |
| **要把一段推进下一段** | ★ 在段末不押／用部分韵。**Partial rhyme 就是专门用来阻止闭合的** |
| **同一个旋律结构要装两种情绪** | 情绪不稳的那一遍不押，稳的那一遍押上 |
| **全曲押得太整齐** | 挑一处最该难受的地方断掉 |

**实例**：Randy Newman "Feels Like Home" 主歌 1 的第 4、8 行**不押**（`arms`、`life`），
造出不稳定，把门推向 pre-chorus；主歌 2 的第 4、8 行**押上了**（`night` / `light`），
一旦"Feels like home"说出口，后面一切都稳了。

★ **部分韵（partial rhyme）的做法**：先定一个阴性词，
再去阳性韵里找能押上它**重读音节**的词，**弱音节那半截不管**——
`moving` / `you`，`striking` / `night`，`lover` / `one`。
声音连上了，结构却没被关住。**阴性那个词通常先出现。**

### 7.3 纪律

★ **每一处不押都要说得出理由，并写进 `rhyme.deliberate_breaks`。**
**为了破坏而破坏，和押到底一样机械。**

**自检动作**：指着那一处问——**"如果这里押上了，会损失什么？"**
答不上来 → 那不是破韵，是没找到韵。

## 8. ★ 中文的押韵与英文不同在哪

**本节只说差别与去处，不列中文韵表。**

| 维度 | 英文 | 中文 |
|---|---|---|
| **韵的单位** | 音节的**元音＋其后的辅音**，且**起音必须不同** | 韵母（含韵头/韵腹/韵尾的归并） |
| **韵表** | 韵典（按元音音素 + 尾辅音排） | ★ **十三辙 → `lw-mandarin`；粤语韵部 → `lw-cantonese`。本 skill 不写** |
| **多出来的一层约束** | 重音（→ `lw-english`） | ★ **字调**：倒字与协音（→ `lw-tone-check` / `lw-cantonese`） |
| **"押不押得上"之外还要问** | 这个韵有多稳 | ★ **同样要问**——§2 的稳定度尺度**与语言无关，中文照用** |

### 8.1 哪些东西可以原样搬到中文

★ **§1（HOT SPOT）、§3（用韵型控制开合）、§4（韵式性格、闭合、奇偶）、§6（意外度）、§7（故意不押）全部通用。**
它们讲的是**韵在结构里的功能**，不是某种语言的音系。

### 8.2 哪些不能搬

| 不能搬 | 原因 |
|---|---|
| **家族韵的辅音亲属表** | ★ 建立在英语辅音的发声位置／清浊之上。中文的近韵关系是**辙口的宽窄与邻辙**，是另一套 → `lw-mandarin` |
| **加音／减音韵** | 依赖"音节末尾可以挂一串辅音"，普通话韵尾只有很少几种 |
| **阳性韵／阴性韵** | 依赖词重音。中文没有对应的词重音体系 → 中文对应的问题是**字调**，见 `lw-tone-check` |

★★ **最要紧的一条**：
**中文押韵押得上，不等于唱出来是那个字。**
**韵和倒字是两个独立的检查，必须分别过。**
（韵 → 本 skill ＋ `lw-mandarin`；倒字 → `lw-tone-check`。粤语两者都更严 → `lw-cantonese`。）

## 10. 收工自检

- [ ] 韵脚**单独抄成一列读过**，读得出这首歌在讲什么（§1）
- [ ] 每个韵脚都**唱过**，不是只看过（§2.2）
- [ ] 说得出**每一段的推进位与解决位各用了哪种韵型**，以及**为什么**（§3.2）
- [ ] 主歌与副歌的**韵脚密度不一样**（§3.3）
- [ ] 主歌各段情绪不同时，**用换韵型解决，没有去改韵式**（§3.3）
- [ ] 韵式的性格**和这段意思的走向一致**（流动 → 通写；分块 → 打碎）（§4.1）
- [ ] ★ **把下一段的意思拿过来套过这个韵式**（§4.3）
- [ ] 韵脚里属于**空洞韵／陈词滥调韵**的不超过一半（§6.1）
- [ ] 每一对韵脚经得起"**除了声音像还有关系吗**"这一问（§6.4）
- [ ] 没有为了押韵**扭曲语法、时态或用古语**（§6.4）
- [ ] `deliberate_breaks` **非空**，且每一处**说得出理由**（§7.3）
- [ ] 中文词：**韵与倒字分别查过**，没有拿一个顶另一个（§8.2）
