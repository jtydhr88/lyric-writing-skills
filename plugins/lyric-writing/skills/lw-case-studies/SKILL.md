# 案例与拆解（Case Studies）

> **这个 skill 不教任何技法。**
> 它只做两件事：**给一张拆一首词的固定表**，和**把具体作品与词人自述索引到别的 skill 上**。
> ★ 任何一条"怎么做"，本 skill 都只给出处与去向，**方法本身在对应的 L1/L2/L3 skill 里**。

## 按任务读哪几节

| 任务 | 读 |
|---|---|
| 要拆一首词 | ★ §1 的表，按 §1.3 的顺序填 |
| 想找一个真实的例子 | §3，或 [reference.md](reference.md) §1 的索引 |
| 想知道职业词人怎么判断好坏 | §2 |
| 三个人说法不一样，听谁的 | ★ §2.4 |
| 自己的词哪里不对说不上来 | §4 反面清单，逐条对 |
| 想用别人的作品练习 | §5 |

## 边界

| 不归这里 | 归哪 |
|---|---|
| 立意五问 | `lw-song-intent` |
| 段落功能、破题句放哪、句式、不对称 | `lw-structure` |
| 意象、具体名词、比喻 | `lw-imagery` |
| 视角、时间锚点、留白 | `lw-narrative` |
| 押韵、韵式、意外度 | `lw-rhyme` |
| 十三辙、平仄、字数与顿、易唱性 | `lw-mandarin` |
| 倒字 | `lw-tone-check` |
| 中国风、典故、文字游戏 | `lw-chinese-style` |
| 说唱、音乐剧 | `lw-rap`、`lw-musical-theatre` |
| 旋律、编曲、配器 | **库一** |
| 交稿前的 AI 味终检 | `lw-ai-tell-audit` |

> ★ **最容易越界的一刀**：拆解时发现"这首词的副歌第三遍改了一个字"，
> **本 skill 只负责记下这件事发生了**；"副歌第三遍该不该改、怎么改"是 `lw-structure` 的事。
> **拆解产出的是证据，不是规则。**

## 1. 拆一首词的固定表

### 1.1 十二行

**每拆一首词，填满这张表。栏目固定，不许换。**

| # | 看什么 | 具体问法 | 对应字段 | 方法归哪 |
|---|---|---|---|---|
| **1** | **立意** | 用**一句人话**说出这首歌只说的那一件事 | `intent.one_thing` | `lw-song-intent` |
| **2** | **对谁说** | 词里的"你"是谁；有没有"你" | `intent.to_whom` | `lw-song-intent` |
| **3** | **时刻** | 说话人站在哪个时间点上 | `narrative.tense_anchor` | `lw-narrative` |
| **4** | **贯穿物件** | 有没有一个东西反复出现；它每次是什么意思 | `intent.anchor_object` | `lw-imagery` |
| **5** | **破题句** | 第一句干了什么：给场景／给动作／给问句／给结论 | — | `lw-structure` |
| **6** | **段落分工** | 主歌管什么、副歌管什么；**第二遍变了什么** | `prosody.sections` | `lw-structure` |
| **7** | **视角** | 第几人称；中途换没换 | `narrative.pov` | `lw-narrative` |
| **8** | **意象系统** | 这些东西为什么会在同一个画面里（**一句话**） | `imagery.system` | `lw-imagery` |
| **9** | **语言层** | 押哪个辙、换没换；句式长短；离口语多远 | `rhyme.che` | `lw-mandarin`、`lw-rhyme` |
| **10** | **不对称与留白** | 哪一行故意短；**该说的地方哪处没说** | `asymmetry`、`narrative.withholding` | `lw-structure`、`lw-narrative` |
| **11** | **与曲的咬合** | 全曲最高音落在哪个字；哪一句旋律被重复用了 | `prosody.peak_syllable` | `lw-tone-check` ＋ 库一 |
| **12** | ★ **可迁移的一条** | **这首词教会我一个什么动作**（一句话，带动词） | — | — |

**外加一行，不进表但必须写**：

> ⚠ **学不来的部分**：这首词里有多少好处依赖**这个歌手、这个时代、这段旋律**？
> 那部分记下来，但**不要当成方法**。

### 1.2 填表的三条纪律

| # | 纪律 | 为什么 |
|---|---|---|
| **1** | **先整首过一遍再动笔**，过的时候什么都不记 | 边听边记会把结构记成句子 |
| **2** | **只写看得见的** | "他想表达孤独"不是观察，"全篇只有一个人称，没有'你'"才是 |
| **3** | ★ **填不出来的格子不许空着，要写"这一栏没有"** | **"没有"是发现**——一首好词没有贯穿物件，说明它靠别的东西撑着，那才是该学的 |

### 1.3 ★ 顺序：从中间填起

**不要从第 1 行开始填。**

```
先填 5–10（破题、段落、视角、意象、语言、留白）  ← 这些是看得见的
再填 11（与曲的咬合）                              ← 需要听
然后回头填 1–4（立意、对谁、时刻、物件）          ← 这些是推出来的
最后填 12                                          ← 一句话
```

★ **理由**：**立意是拆出来的，不是看出来的。**
先写立意，你会把自己的印象写上去，然后在下面九行里找证据来圆它。
先填看得见的东西，立意会自己浮出来——**而且常常和你一开始以为的不一样**。

姚谦记过一个同样方向的做法：写《答案》时**最先设定好"答案"这个大主题**，
然后在既定旋律与主副歌结构下**分布大主题底下的延伸细节**（姚谦 p0005）——
★ **写的时候从上往下，拆的时候从下往上。** 两个方向不能混。

## 2. 三个人的写作习惯与判断标准

★ **下面每一条都标了是谁说的。三个人不是一套方法的三种说法，他们真的不一样（§2.4）。**

### 2.1 姚谦

| 条目 | 说法 | 页 |
|---|---|---|
| **破题** | **「一首歌破题的第一句词，往往决定了一首作品的生死」**；破题要在最短时间内抓住听者的好奇心 | 姚谦 p0005、p0002 |
| **站位** | ★ **站在聆听者的位置思考，不是站在创作者的位置** | 姚谦 p0001 |
| **副歌微调** | 副歌旋律为了好唱好记通常不变，**但微调字词来加重情绪**——《旅行的意义》第一次"让你动心"，第二次"让你分心" | 姚谦 p0001 |
| **节制** | 副歌开头有三个急促叠音，本可以放叠词强化，**他故意回避，用平淡语句**；判断是**「节制的笔法，更容易触动听者内在的情绪」** | 姚谦 p0003 |
| **空镜头** | **「就像电影，当主人公缺席，画面定格在一个空镜头时，才最煽情」** | 姚谦 p0003 |
| **去鸡汤** | 检查歌词是否落入俗套，**拿掉"承诺""正能量"这类字眼** | 姚谦 p0003 |
| **压住自己** | **「创作时，得适当压抑自己的情感，维持客观，才可以让读者也站在你的位置去看这个故事」** | 姚谦 p0005 |
| **语态** | 录下自己日常说话并听写，认识惯用语；**写完歌词朗读并录音** | 姚谦 p0004 |
| **动笔前定情境** | **「对一个人说」还是「对众人说」；公共场合还是隐秘场合** | 姚谦 p0004 |
| **特定状态法** | **「把自己放在某个特定的非常状态下，就有可能写出异于常规的作品」** | 姚谦 p0005 |
| **诚实** | **「诚实会比炫技的文字更为动人」**；创作不提供最终答案，只求**这个阶段最能说服自己的答案** | 姚谦 p0005 |
| **什么时候算写完** | ★ **「作品的完成不是写完的时候，而是听者产生解读的时候」** | 姚谦 p0004 |

### 2.2 张藜

| 条目 | 说法 | 页 |
|---|---|---|
| **歌词是什么** | **「歌词就是与音乐结合了的诗」**；理想形式是**「谱上曲子能唱，离开曲子也能诵，琅琅上口……通俗易解，绝不平庸」** | 张藜 p0028、p0033 |
| **源头** | **「生活是歌词创作的唯一源泉」**；反对**主题先行论**，认为它必然导致概念化、雷同化 | 张藜 p0029、p0049、p0066 |
| **构思立意四标准** | ★ **新、巧、深、明** | 张藜 p0099–p0107 |
| **取其一点** | 主题是**「象穿糖葫芦的那根竹签子」**；收拢琐碎形象后**善于取其一点**，切忌铺排过大 | 张藜 p0137 |
| **顺蔓摸瓜** | 写作中**切忌心猿意马**，要顺着一条蔓捋下去，**不可分路扬镳** | 张藜 p0144 |
| **铺排** | 高潮出现前要**层层逼近**；**「高的要用矮的衬，胖的要用瘦的陪」**，红花要绿叶衬 | 张藜 p0127 |
| **情绪统一** | ★ **一个小段落里情绪要统一**；若"一句一个情绪，一段四句四个情绪符号"，**作曲者会像面对梦呓一样无法捕捉** | 张藜 p0023 |
| **头三句** | **「每写一首词，要善于选择情感的闸口。也就是"头三句"」** | 张藜 p0117 |
| **标题** | 标题是**「歌词的眼睛」**，要醒目又简洁上口；**占作品百分之五十的比重** | 张藜 p0150–p0151 |
| **窄韵** | ★ **窄韵倒容易出好词**；宽韵词汇多，但用滥了显得平庸乏味——**「经验证明，窄韵都经常出现新词汇的」** | 张藜 p0150、p0179 |
| **朗诵** | 写完让亲友听朗诵，考核哪些**读起来很拗口**；朗诵是把作品投入实践检验的第一步 | 张藜 p0150、p0180 |
| **冷处理** | **「创作时是热的，创作完毕要冷处理」**；他为一首词写过四稿、五稿直到十稿 | 张藜 p0150、p0055–p0056 |
| **三道墙** | ★ 挡住进步的三样：**懒惰、满足、出世（急着定稿）** | 张藜 p0190–p0191 |
| **力戒三字** | ★ **平、散、长**——**「写词不要求全。一求全，必然平、散、长」** | 张藜 p0182 |
| **篇幅** | **一段最好八至十句，两段最好，三段也无妨** | 张藜 p0182 |

### 2.3 洪源

| 条目 | 说法 | 页 |
|---|---|---|
| **歌词是什么** | **「歌词是情的载体，是意的物化」**；**「歌词是意的岩浆在情的断层间喷发出来的火」** | 洪源 p0011 |
| **词人的心** | 要有**童心**（圣洁，才发现得了真善美）与**大心**（博爱，才表现得了真善美） | 洪源 p0013 |
| **词人的眼** | 眼睛要像**凸透镜、凹透镜、望远镜、潜望镜**；★ **但千万不要戴眼镜**——镜片有颜色会让一切变单调，有灰尘会让一切变模糊，有折光会让一切变得奇形怪状 | 洪源 p0013–p0015 |
| **个性** | ★ **「没有个性便没有你存在的必要，没有个性更没有属于你的作品」** | 洪源 p0016 |
| **姿态** | **「词人是献花者，而不是垂钓者」** | 洪源 p0016 |
| **诗与词的分界** | **诗静止在纸上，占有空间，可以反复阅读；歌词流动在曲内，占有时间，只能顺序听下去** | 洪源 p0018 |
| **给作曲家七样东西** | 鲜明的**表情符号**、**感情发展的线索**、**律动的形式**、**独特的艺术角度**、可深化美化的**形象**、可体味的**意境**、**可以自由飞翔的空间** | 洪源 p0022–p0023 |
| **不是半成品** | **「歌词不是半成品」**、**「歌词不是寄生草」**——离开曲调就失去生命力的，不是好词 | 洪源 p0024–p0025 |
| **语言九条** | 通俗（似俗非俗，是**筛选过的口头语**）、简练、生动、鲜明、形象、准确、真实、新颖、深沉 | 洪源 p0029–p0031 |
| **四反** | ★ **反白、反直、反露、反满**——**「艺术最大的秘诀就是隐的艺术」**，词面之外要有**潜台词**；"满"是一种**浮肿** | 洪源 p0031–p0032 |
| **听觉陷阱** | ★ 注意**多义字与同音词**，**「切不可使人产生错觉」** | 洪源 p0033 |
| **景为情设** | 区分**眼中之景**（自然状态）与**心中之景**（构思中的）；**「景从来都是为情服务的」** | 洪源 p0033–p0034 |
| **立意是核** | 作品不可无核，**立意就是核**；无核之作**「作者无立意，信笔成章」** | 洪源 p0035 |
| **词外功夫** | 引陆游**「汝果欲学诗，功夫在诗外」** | 洪源 p0036 |

### 2.4 ★ 他们的分歧

**这一节比上面三节有用。分歧的地方就是你必须自己选边的地方。**

| 争点 | 姚谦 | 张藜 | 洪源 |
|---|---|---|---|
| **含蓄到什么程度** | **节制**：情绪最重处刻意用平淡语句（姚谦 p0003）；结局**只丢出可能性**让听者想象（姚谦 p0001） | ★ **偏明言**：**「诗强调余味，词讲究明言」**，**「词则唱通即逝，一听就得明白」**（张藜 p0154）——但同一本书里又专门写了一节**「词要学诗」**讲含蓄（张藜 p0163） | ★ **偏含蓄**：反白反直反露反满，要有潜台词（洪源 p0032）——但也说**「歌词在宣叙里最好明言其事」**（洪源 p0018） |
| **词能不能离开曲活着** | 更贴着演唱者与旋律走（如按旋律起伏决定哪句放重话，姚谦 p0004） | **「谱上曲子能唱，离开曲子也能诵」**（张藜 p0033） | ★ 更硬：**「歌词不是寄生草」**，离了曲就没生命力的不是好词（洪源 p0025） |
| **给曲作者留多少** | 会为一个字和作曲者沟通到旋律层面（姚谦 p0004） | ★ **「歌词作者的设想不能也不应该去代替作曲家的安排……如若设计得过于具体，我倒觉得会弄巧成拙」**（张藜 p0115–p0116） | ★ **「那些逐字、逐句，亦步亦趋地为词写调子的人不是词作者真正的知音」**；请作曲家把词当**引线**（洪源 p0023） |
| **口语还是书面语** | **回归口语**，抛开字数限制用接近自己语言习惯的大白话（姚谦 p0004） | 两头都要：**口语美**（张藜 p0161），但也主张**适量运用不常用的语言**，学诗的华丽美（张藜 p0171–p0172） | **通俗＝似俗非俗**，是**筛选过的**口头语，切不可粗俗（洪源 p0029） |
| **词写给谁** | **动笔前先定"对一个人说"还是"对众人说"**（姚谦 p0004） | ★ **「词作家则要求'目中有人'」**——借**歌唱主人公**的身分说话，人物是假托（张藜 p0159） | ★ **「尊重自我」**——尊重自我的感情、理性、信念、使命（洪源 p0015） |

★★ **怎么用这张表**：

1. **不要调和它们。** 三个人的位置差异来自**他们写的是什么歌**——
   同一根轴上（明言 ⇄ 含蓄、自我 ⇄ 人物、词独立 ⇄ 词贴曲），**你这首歌要站在哪一格，是风格层的决定。**
2. **注意一件事**：三个人**没有一个站在两端**。
   最偏明言的张藜专门写了一节让词学诗的含蓄，最偏含蓄的洪源同样说歌词要明言其事。
   ★ **两端都是错的，这是三个人唯一完全一致的地方。**
3. **有一条三个人都说**：**写完要念出来。**
   姚谦朗读并录音（p0004）、张藜开朗诵会验证（p0150、p0180–p0181）、洪源把音乐性当成通体贯穿的要求（p0027）。
   → 这条直接进 `lw-workflow` 的收尾动作。

## 3. 成篇拆解

★ **下面每一首都按 §1 的十二行拆。引用限于说明所必需的短句。**

### 3.1 《旅行的意义》（姚谦 p0001）

| # | 拆解 |
|---|---|
| 1 立意 | **歌名说的是旅行，最终想说的是"你离开的原因"** |
| 2 对谁说 | 一个喜欢旅行的男性；**旁观者视角看着他** |
| 3 时刻 | 他已经走了之后 |
| 4 物件 | 地图、夜的巴黎、书本里的真理、**为我寄出的每一封信** |
| 5 破题 | 以"你"的行为起头，不写自己 |
| 6 段落 | 主歌罗列他做过的事；**副歌两遍只改一个词** |
| 7 视角 | 第一人称看第二人称，**但"我"几乎不出现** |
| 8 意象系统 | **旅行的全套物件**：地图、城市、书、信 |
| 9 语言 | 接近口语 |
| 10 留白 | ★ **从头到尾没说"你不爱我了"** |
| 11 与曲 | 副歌旋律不变，靠**换字**加重 |
| 12 ★ 可迁移 | **副歌第二遍换掉一个字，让力度变重**："却说不出在什么场合我曾让你**动心**"→"却说不出在什么场合我让你**分心**"；结尾用"说不出**离开的原因**"呼应"说不出**旅行的意义**" |

⚠ **学不来的部分**：歌名与结论的反转依赖听众先接受"这是一首关于旅行的歌"。
**这个把戏一首歌只能用一次。**
→ 换字的方法归 `lw-structure`；留白归 `lw-narrative`。

### 3.2 《记念》（姚谦 p0005）

| # | 拆解 |
|---|---|
| 1 立意 | **想念的是记忆里营造出来的形象，不是那个真实的人** |
| 2 对谁说 | 一个还在想念中的"你"（歌者） |
| 3 时刻 | 一次见面**之后**才发现的那一刻 |
| 4 物件 | ★ **气味**——"他的样子已改变，有新伴侣的气味" |
| 5 破题 | 以"想念变成一条线，在时间里面蔓延"起，先给一个可见的形状 |
| 6 段落 | 主歌一：还在想念；主歌二：见面发现变化；副歌：揭开真相；主歌三：给出理解 |
| 7 视角 | ★ **第三者视角写接近第一叙述者的感触** |
| 8 意象系统 | 季节错位（"他在春天那一边，你的秋天刚落叶"） |
| 9 语言 | 冷，带一点理性——为匹配歌手旋律里"一点酷与理性"而选 |
| 10 留白 | 没有一句指责 |
| 11 与曲 | 副歌承担点题 |
| 12 ★ 可迁移 | **用一个感官细节（气味）代替"他变了"这个结论** |

★ **作者自己给的判断**：**「我没有在歌词里放太多主观的情感，而是用第三者的视角描述接近第一叙述者的感触与故事」**（姚谦 p0005）。
→ 视角归 `lw-narrative`；气味这类非视觉细节归 `lw-imagery` 的感官分布。

### 3.3 《家Ⅱ》罗大佑（姚谦 p0005 的分析）

★ **这是三遍副歌逐步具体化的教科书例子。**

| 遍 | 副歌要的东西 | 变化 |
|---|---|---|
| 一 | **「温暖的陷阱」**，让"冰冷的心灵"有个**想到了家的憧憬** | ★ 刻意避开"给我家"这个具体说法 |
| 二 | **「温暖的真情」**，让"漂泊的心灵"有个**找到了家的心情** | **"家"第一次被说出来** |
| 三 | **「温暖的家庭」**，让"出门的背影"有个**回到了家的心情** | **从"家"到"家庭"，从憧憬到切实归返** |

主歌同步推进：第一遍"每一首**想你**的诗"，第三遍"每一首**苍老**的诗"——
姚谦的判断是**「"苍老"比第一遍的"想你"更有现实感」**（姚谦 p0005）。

| 12 ★ 可迁移 |
|---|
| **副歌重复三遍时，让同一个位置上的那个词一次比一次具体**：憧憬 → 心情 → 家庭。**不改结构，只改一个名词的清晰度。** |

→ 归 `lw-structure`（副歌变奏）与 `lw-imagery`（抽象→具体）。

### 3.4 《林海恋歌》（张藜 p0128–p0129）

★ **这首的价值在于作者把自己的铺排逻辑逐句讲了出来。**

| # | 拆解 |
|---|---|
| 1 立意 | 全词**突出一个"恋"字**——这是主旨；"前辈为后代造幸福，我们就是栽树人"是主题 |
| 5 破题 | **「远望朵朵云，近看片片林」**——★ **从感觉形象入手，不从概念着笔** |
| 6 段落 | 远景 → 拟人 → 直陈"爱林海" → 动作高潮 |
| 8 意象系统 | 一片林子里的东西：云、林、沙丘、荒岭、树叶、露水 |
| 11 与曲 | 曲调把高潮放在**"恋林海"**以及结尾处 |
| 12 ★ 可迁移 | **高潮句之前要层层逼近**：写景（云、林）→ 拟人（"沙丘挎上翠玉带，荒岭披起绿纱巾"）→ 直说（"走林海，总是春"）→ **落到一个身体动作上**（"摘片树叶吻一吻"） |

★ **作者的铺排原则**：好的铺排像锣鼓经的"急急风"，**「每一句和每一句都死死咬住，象大小齿轮相扣一样紧密」**（张藜 p0127）；
反面是**「语语泄气」**——衬托句平淡且与高潮句无关联，步步逼不上去（张藜 p0127）。

⚠ **学不来的部分**：这首的题材与年代定了它的语气。**可迁移的是铺排的梯子，不是那几个词。**
→ 归 `lw-structure`。

### 3.5 《北京颂歌》（洪源 p0069–p0070；张藜 p0025 的音节分析）

★★ **这是两本书里唯一互相咬合的一首——一个人写的，另一个人拿它当范例讲节奏。**

张藜数过它的音节安排（张藜 p0025）：

```
头两句      每句 5 音节
三、四、五句 每句 2–4 音节
六、七句    每句 4–5 音节
结尾句      每句 4 音节
```

他的判断：**这种多变（不是巨变而是细微之变）的音节组成一个和谐的整体，读起来铿锵顿挫、一气呵成**（张藜 p0025）。

对照洪源那一侧的文本结构（洪源 p0069–p0070）：

| # | 拆解 |
|---|---|
| 5 破题 | 先给一个**看得见的画面**再给判断 |
| 6 段落 | 明确标着（一）（二）两段；**核心句"啊，北京啊北京！"在两段同位置出现** |
| 9 语言 | ★ 四个名词短语并列做定义（"祖国的心脏，团结的象征，人民的骄傲，胜利的保证"），**每句 4–5 字** |
| 12 ★ 可迁移 | **各句字数要"细微之变"而不是"完全整齐"或"忽长忽短"**：5、5 / 2–4 / 4–5 / 4——**变化幅度控制在一两个字以内** |

★★ **这条直接对着 LYR-LINT 第 3 条**（各段字数不许完全相同）：
**它给出了"不相同"的尺度——不是长短句乱跳，是每句差一两个字。**
→ 归 `lw-mandarin` §4（顿与长短句）与 `lw-structure`。

### 3.6 《四季思乡曲》（洪源 p0076–p0077）

| # | 拆解 |
|---|---|
| 1 立意 | 一个在异乡的人，四个季节各想起一个家里人 |
| 4 物件 | ★ **每段一件具体物**：断了线的风筝、织女星、小蜻蜓、密密缝的棉衣 |
| 6 段落 | ★ **四段共用一个格子**：`季节 ＋ 故乡的某个景 ＋ 某个亲人带我做一件事 ＋ 当年如何 ＋ 如今如何` |
| 7 视角 | 第一人称，从头到尾 |
| 8 意象系统 | **一个家＋四季**，人物依次是姐姐、奶奶、爹爹、妈妈 |
| 10 留白 | ★ 每段末句只说"如今"的处境，**不说为什么回不去** |
| 12 ★ 可迁移 | **做一个四格模子，然后只换格子里的人和物**——变奏靠替换，不靠重写 |

★ **这一手和 §3.3 的《家Ⅱ》是互补的两种重复**：
**《家Ⅱ》改同一个词让它更具体；这首换掉整组名词而保持句式不变。**
→ 两种都归 `lw-structure`。

### 3.7 ★ 改稿对照：三个初稿变成什么样

**这是本 skill 最实用的一节——因为你看得到中间那一步。**

| 作品 | 初稿 | 改后 | 作者的判断 | 页 |
|---|---|---|---|---|
| **《绿海玫瑰》** | 「草原开玫瑰，绿海更妩媚，玫瑰容颜好，满身香滋味。」 | 「草原开玫瑰，姑娘走几回。摘花心不忍，人走花香追！」 | ★ 初稿**「只写了景，并没完成人爱花开的心灵描述」**；**「只有写到心灵深处，才算初步完成了题材与主题的开掘」** | 张藜 p0040–p0041 |
| **《月牙》** | 起初写"月下人相爱""月影照西窗"一类**华丽辞章** | 「你爱天上的满月，我爱云缝里的月牙。」 | 改后才**「觉得这个小葫芦，刚刚画出个雏型儿」** | 张藜 p0084–p0085 |
| **《都说他黑》** | （定稿）「都说他黑，／都说他黑，／黑得象块煤；／这我不怪罪，／我也没理会，／我看他很美。」 | ★ **反面改写**：硬套成七字句「都说他呀长得黑，／黑得好象一块煤……」 | **「这样硬性安排七字句式的节奏，既破坏了口语美，更破坏了这位姑娘的性格真实」** | 张藜 p0120–p0121 |

★ **三条共同点**：

1. **改动方向全都是"从景移到人"**——玫瑰移到看玫瑰的姑娘，月亮移到"你爱哪个我爱哪个"。
2. **改后都变短了、变土了。** 华丽辞章是被删的那一侧。
3. ★ **《都说他黑》那条是倒着演示的**：作者先给成立的那一稿，再演示把它规整化会死在哪。
   **句式服从人物性格，不是人物服从句式。**

→ 归 `lw-song-intent`（写到心灵＝写到那一件事）、`lw-mandarin` §4（句式与顿）。

**另有一例是"删"而不是"改"**：
《萨日朗》的修改是**删掉"半导体、獐狍、套杆、风餐露宿、那朵光荣花"这一大堆形象**，
只保留**富有草原色彩的炒米、奶干、砖茶**——理由是**「用多了，反而把炒米的香味搅没了」**（张藜 p0109）。
★ **结论句**：**「只有经过集中，经过删减，才能使构思立意明确起来」**（张藜 p0109）。

更多案例见 [reference.md](reference.md) §1。

## 4. 反面案例

### 4.1 张藜的「平、散、长」

> **「写词不要求全。一求全，必然平、散、长」**（张藜 p0182）

| 症状 | 书里的描述 | 页 |
|---|---|---|
| **平** | **「歌词的致命之弊」**——缺乏特性、没有独特的感受和巧妙构思，写的是**「大家都写过的轻车熟路老套数」** | 张藜 p0182 |
| **散** | **「事无巨细，都点几笔……东也没写透，西也没抓着」**；像**「蜻蜓点水，浮面莲蓬，没有深根」** | 张藜 p0182 |
| **长** | 一段多至十四、五句，句子多而长；**「有话则长，无话则短」** | 张藜 p0182 |

★ **"平"这一条与 `lw-ai-tell-audit` 完全同构**——
**"大家都写过的轻车熟路老套数"就是"这四段可以属于任何一首歌"的旧版说法。**

### 4.2 张藜点名的其他毛病

| 毛病 | 书里的例 | 页 |
|---|---|---|
| **一句一个情绪** | "一句一个情绪，一个情绪变幻一个腔调，一段四句四个情绪符号"，**「象梦呓一样令人无法捕捉」**——作曲者接不住 | 张藜 p0023 |
| **夸张到失真** | 让瞎子英雄抱起根本抱不动的导洪管以示壮观；用"血涂"二字形容建筑工人的汗水 | 张藜 p0083 |
| **太实** | **「实得几乎完全等同于生活的本身，琐细而缺乏典型概括」** | 张藜 p0074 |
| **太虚** | **「虚得几乎完全失去了生活的依据，飘渺而无有生活气息」** | 张藜 p0074 |
| **立意不明确** | 初稿《礼物》**「立意显得不明确，形象取得不集中……还都是自然主义的描写」**；改后集中在"情别"一个关节上 | 张藜 p0107–p0108 |
| **游离主题** | 写《翠湖》却接着去写春城；**「把它删掉，就更显得鲜明集中，把赘生的枝叉统统砍掉」** | 张藜 p0146 |
| **语语泄气** | 衬托句平淡且与高潮句无关联，逼不上去 | 张藜 p0127 |
| **主题不集中** | **「等于没主题，没击到一点上，形同虚设」** | 张藜 p0067 |

### 4.3 洪源的「白、直、露、满」

| 反什么 | 书里的说法 | 页 |
|---|---|---|
| **白** | **「不含丹青，不蓄甘酸」**，白是无色无味；歌词该像浓茶、醇酒，**不能像"一瓢白水，一旦落肚，便无可追寻"** | 洪源 p0031–p0032 |
| **直** | **「不可象十里长街，一眼望穿，一览无余」**；引古人**「正言直述，易于穷尽，而难于感发人意」** | 洪源 p0032 |
| **露** | **「露是暴露，露骨，锋芒毕露」**；**「艺术最大的秘诀就是隐的艺术」**——词面之外还要有潜台词 | 洪源 p0032 |
| **满** | **「满是填塞，拥挤，重叠，堆砌，满是一种'浮肿'」**；不要写得**「针插不进，水泼不入，满满当当」** | 洪源 p0032 |

**另外两条**：

- ★ **戴有色眼镜**：镜片有颜色→一切变单调；有灰尘→一切变模糊；有折光→一切变得奇形怪状（洪源 p0014–p0015）
- ★ **无核之作**：作者**没有立意、信笔成章**，作品就是个"无核蜜桔"（洪源 p0035）

### 4.4 姚谦点名的毛病

| 毛病 | 说法 | 页 |
|---|---|---|
| **鸡汤字眼** | 检查是否落入俗套，**把"承诺""正能量"这类字眼拿掉** | 姚谦 p0003 |
| **心灵鸡汤式形容词** | 写《自己》时**不使用心灵鸡汤式形容词，把自己放低** | 姚谦 p0001 |
| **煽情** | 副歌最重处**故意不用叠词**，反而写"听起来连自己都觉得太煽情" | 姚谦 p0003 |
| **只顾自己** | **写作者位置** vs **聆听者位置**——他主张后者 | 姚谦 p0001 |

★ **把 §4 当清单用**：自己的词写完，逐条对一遍。
**命中哪条，就去那条对应的 skill**（平→`lw-ai-tell-audit`；散→`lw-structure`；满→`lw-imagery`；白→`lw-narrative` 的留白）。

## 5. 拿别人的作品练习

本库自己读过的分层语料样本（540 首的分布与十二个按十二行表填好的条目，不含原文）在 [reference-corpus.md](reference-corpus.md)（分布与十二条）与 [reference-corpus-2.md](reference-corpus-2.md)（再二二十条，按类型分组），练习时先对照同类条目。

**三个人各给了一种练法。**

| 练法 | 怎么做 | 出处 |
|---|---|---|
| **翻唱填词** | ★ **用已完成的外国作品填中文词**——旋律与结构是现成的，练的纯粹是词这一侧 | 姚谦 p0002 |
| **朗诵验证** | 写完念给别人听，**考核哪些"读起来很拗口"**，哪些该增该删；验证人物化、口语化、情绪推进、生僻语言是否奏效 | 张藜 p0150、p0180 |
| **媲美（查重）** | ★ **动笔前先调查同类题材别人用过什么手法，看有否不谋而合**；学他们**但不蹈旧路**，是要**重辟新径** | 张藜 p0141 |
| **初稿／定稿对照** | 找同一首词的两个稿子并排看（见 §3.7） | 张藜 p0040–p0041、p0084–p0085 |
| **一题多写** | **一根翠竹可以做出多少文章**——同一个物件，看不同作者各挖出什么 | 张藜 p0141–p0143 |
| **录自己说话** | 录下日常说话并听写，认识自己的惯用语；写完朗读并录音 | 姚谦 p0004 |

★ **"媲美"那条最容易被跳过，也最该做**：
**你以为的巧思，往往是别人二十年前的标准做法。** 先查再写。

| 字段 | 拆解时怎么用 |

## 7. 用完自检

- [ ] 十二行**全部填了**，没有空格子（"这一栏没有"也算填）
- [ ] ★ 按 §1.3 的顺序填的：**先 5–10，再 11，最后回头填 1–4**
- [ ] 第 1 行的立意是**一句人话**，不是主题词
- [ ] 每一格写的都是**看得见的事实**，不是"他想表达……"
- [ ] 第 12 行是**一句带动词的话**
- [ ] ★ 写了**「学不来的部分」**那一行
