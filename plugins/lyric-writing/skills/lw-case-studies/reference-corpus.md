# 语料层：华语流行歌词的读后分析（分层样本）

> 来源：华语歌手榜前 100 位歌手的 4674 首歌做了段落标注，从中分层抽样并把语料里全部粤语歌读完，共 641 首（国语非说唱 487、说唱 100、粤语 36、其他 18），
> 逐首按 SKILL §1.1 的十二行表读出来。**条目只存结构参数与读后分析，不存任何原文句子**。年代没有分层（语料没有年份字段）。
>
> **这些数有多硬**：抽 59 首让另一个模型盲判，判型一致 75%（自报把握高的 87%，分歧几乎全在态度型与情境型之间）、语言 90%、人称 80%、有无物件 75%、破题句 66%、末遍副歌 61%、hook 位置 59%。
> 一致率低于七成的栏当粗参照；末遍副歌是否改动、副歌占比这些能逐字比对的，以 `lw-structure` §6.0 的全量比对数为准。

## 1. 分布：一首华语流行词通常长什么样

**国语非说唱（n=487）**

| 栏 | 分布 |
|---|---|
| plot_type | 态度型 64%、情境型 24%、说理型 8%、叙事型 5% |
| 人称 | 第一 71%、混用 22%、第二 5%、第三 2%；中途换人称 17% |
| 时刻 | 混合 33%、此刻 30%、无时间点 18%、回望过去 16%、预想未来 3% |
| 破题句 | 场景 40%、独白 33%、动作 8%、结论 8%、问句 8% |
| 贯穿物件 | 有 67%；出现次数中位 4；意义偏移只 21% |
| 意象成系统 | 72% |
| 语域 | 口语 51%、书面 37%、混合 12% |
| 韵 | 换韵 51%、一韵到底约四成、不押 9% |
| 末遍副歌（读出来的，粗参照） | 无变 43%、改字 25%、加尾 21%、重写 4% |
| hook 位置（粗参照） | 段首 62%、段尾 22%、首尾都有 10% |
| 副歌占比按类型 | 态度 0.49、情境 0.47、叙事 0.43、说理 0.47（n=313／115／22／37） |
| 有物件按类型 | 情境 86%、叙事 77%、态度 60%、说理 59% |

**说唱（n=100）**：态度型 67%、情境型 22%、叙事型 8%；第一人称 86%；破题句独白 32%、结论 27%、场景 25%；换韵 75%；末遍副歌无变 65%；hook 段首 48%、首尾都有 22%；有物件 54%。
**粤语（n=36，语料里的粤语歌全部）**：态度型 69%、情境型 17%、说理型 8%、叙事型 6%；第一人称 81%；破题句独白 44%、场景 39%；末遍副歌加尾 33%、改字 31%、无变 19%、重写 11%；hook 段首 56%、段尾 28%；有物件 61%；换韵 33%。只有态度型一格够 8 首（n=25：副歌占比 0.51，有物件 52%），其余格出不了数。

**按年代**（国语非说唱样本，年份来自公开发行元数据）：plot_type 四十年基本不动，态度型 60% 到 67%、叙事型 3% 到 6%（2000s n=73、2010s 154、2020s 245）；第一人称从九十年代的 91% 降到 2020s 的 69%（1990s n=11 只当参照）；有贯穿物件稳定在 67%；换韵率在 41% 到 64% 之间波动，看不出方向。

**读法**：华语流行的底色是"我对你、站在此刻、态度型、第一句给场景、副歌段首放 hook、末遍或不动或改几个字、换韵"。
偏离这条底线的每一项都是选择，本库各 skill 讲的就是什么时候值得偏离。粤语与国语的可见差别：末遍更爱动（改字加尾合计六成）、第一句更多直接独白、换韵少。

## 3. 怎么用这些条目

- 要写某一类时，先看同类样例的第 5、6、10 行（破题、段落分工、留白），那是看得见的做法；第 12 行是一句话的动作，可以直接当练习题。
- 条目里"意义无偏移"的物件占多数，别因为物件没变意就判它没用，它在用位置说话。
- 这里的数是参照分布，写进 LYR-SPEC 的仍是你自己的选择；偏离分布时把理由写进 `intent.one_thing` 或 `asymmetry`。
