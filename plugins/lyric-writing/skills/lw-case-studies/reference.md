## 1. 按技法查案例

### 1.1 破题（第一句）

| 作品 | 第一句干了什么 | 页 | 方法归 |
|---|---|---|---|
| 《家Ⅱ》 | 「每一首想你的诗，写在雨后的玻璃窗前」——★ 姚谦：**「一首歌破题的第一句词，往往决定了一首作品的生死」** | 姚谦 p0005 | `lw-structure` |
| 《像艳遇一样忧伤》 | 「我想我曾亲吻过你，但我说不好是在哪里、在何时」——**带电影影像感**，破题要在最短时间抓住好奇心 | 姚谦 p0002 | `lw-structure` |
| 《秋天别来》 | 首句「知道你很快有了新恋情」**直接点出爱情结束的主轴**；把整首词当长篇小说的**「序」** | 姚谦 p0002 | `lw-structure` |
| 《听一千遍后》 | 破题「为什么还流眼泪呢」——★ **"还"字为后文"听一千遍"做铺垫** | 姚谦 p0001 | `lw-narrative` |
| 《树》 | 「我站在夏日的黄昏，山之巅」——**以景抒情，先给明确画面** | 姚谦 p0004 | `lw-imagery` |
| 《祖国之爱》 | 「谁没有泪珠儿滚滚的时候」——张藜称之为**选对了"情感的闸口"**，即"头三句" | 张藜 p0117 | `lw-structure` |
| 《林海恋歌》 | 「远望朵朵云，近看片片林」——★ **从感觉形象入手，不从概念着笔** | 张藜 p0129 | `lw-imagery` |
| 《答案》 | 「云很淡，才显得天那么蓝」先给**宽阔空间**，第二句才点题 | 姚谦 p0005 | `lw-structure` |
| 《莫笑游子爱说家》 | 「游子见面三句话，句句不离家」——先给一个**可观察的行为**再给判断 | 洪源 p0080 | `lw-narrative` |

### 1.2 段落推进与副歌变奏

| 作品 | 怎么推进 | 页 | 方法归 |
|---|---|---|---|
| 《家Ⅱ》 | ★ 三遍副歌同位置的名词一次比一次具体：**陷阱→真情→家庭**；主歌同步"想你"→"苍老" | 姚谦 p0005 | `lw-structure` |
| 《旅行的意义》 | ★ 副歌旋律不变，**只换一个词**加重力度："动心"→"分心" | 姚谦 p0001 | `lw-structure` |
| 《窗外的天气》 | Bridge 两遍：「我只是你的过去」→「我只是你**一段**过去」——**多两个字让演唱者有想象空间** | 姚谦 p0003 | `lw-structure` |
| 《生命中的精灵》 | 主歌一直接破题 → 副歌拉回共同经验 → **主歌二更具侵略性，从抽象心情转向具象画面** → 副歌回归大众立场 | 姚谦 p0001 | `lw-structure` |
| 《一首歌》 | 副歌一用假设语气，副歌二转坚定语气，再"一退一进，先邀后求" | 姚谦 p0001 | `lw-structure` |
| 《四季思乡曲》 | 四段共用一个格子，**只换季节、景、亲人、物件** | 洪源 p0076–p0077 | `lw-structure` |
| 《我的米兰》 | 两段副歌句式完全一致，**只替换三个核心词**（真／善／美 ⇄ 志／意／情） | 洪源 p0048–p0049 | `lw-structure` |
| 《自己》 | 三遍同旋律主歌做**罗列／宣言**，副歌只有一句唱七遍，**结尾用一半主歌旋律做结论** | 姚谦 p0001 | `lw-structure` |
| 《奇妙能力歌》 | 十一段，每段四句、每三句后下一个结论；**每段一个关键词**（看过／知道／听过……），第十一段是"想要" | 姚谦 p0003 | `lw-structure` |
| 《欢乐的长白山》 | 作者原按分节歌写，**曲作者建议改成回旋曲式 AB、AC、AD、AE、A** | 张藜 p0130–p0131 | `lw-structure` ＋ 库一 |

### 1.4 意象与物件

| 作品 | 怎么用 | 页 | 方法归 |
|---|---|---|---|
| 《生命中的精灵》 | ★ **「你额头的两道弧线」**代替"眉眼"——具体且出人意表 | 姚谦 p0001 | `lw-imagery` |
| 《记念》 | 用**气味**（"有新伴侣的气味"）代替"他变了"这个结论 | 姚谦 p0005 | `lw-imagery` |
| 《陪伴者》 | **「就像一座岛屿旁边的岛屿互望不离」**——选岛屿是因为它**独立、有生命、画面具象** | 姚谦 p0003 | `lw-imagery` |
| 《当我在这里》 | ★ **刻意错配感官动词**：闻到秋光、沐浴蝉鸣、枕着白雪、听见杨絮 | 姚谦 p0004 | `lw-imagery` |
| 《我爱夏卡尔》 | 从画作里提取"浮在半空中"，转成**"恋爱中的人，都是浮着的"**；结尾放一个"流泪"一闪而过，避免情绪单一 | 姚谦 p0001 | `lw-imagery` |
| 《轻？》 | ★ **"万花筒"式**：先列出与核心概念"轻"相关的一切（蒲公英、燕子……），再顺着延伸找意象 | 姚谦 p0004 | `lw-imagery` |
| 《小溪》 | 用**无数条别的河**（大河、清河、浑河）去丰富门前那一条，使它有共性与普遍性 | 张藜 p0079–p0081 | `lw-imagery` |
| 《温泉》 | 把温泉与"祖国母体的奶浆"联系起来，**这个联想成为全篇构思** | 张藜 p0105–p0106 | `lw-imagery` |
| 《月亮》⇄《望明月》 | ★ 同题材两种做法：一首用**多重比喻**（小船、银镰、蜜瓜、手鼓、镜子）走个性；一首只抓**"望明月，思故乡"**走共性 | 张藜 p0093–p0095 | `lw-imagery` |
| 《社员弯腰闻谷香》 | 同一题材里别人写牧鹅、写算账，这首**把镜头完全集中到一穗谷子上** | 张藜 p0100 | `lw-imagery` |
| 《跳蚤之歌》 | 从"跳蚤咬人发痒"这一**固有的真实**出发，加官封爵的情节是**由生活真实跨进艺术真实的梯子** | 张藜 p0073 | `lw-imagery` |
| 《四季思乡曲》 | 每段一件具体物：断线的风筝、织女星、小蜻蜓、密密缝的棉衣 | 洪源 p0076–p0077 | `lw-imagery` |
| 《她在等》 | 「手儿摇着孩子的梦，眼儿望着床前的灯」——**用两个同时进行的动作写等待** | 洪源 p0141 | `lw-imagery` |
| 《姑娘含笑去梳妆》 | 靠一个生活细节（"爹爹寄来一封信，向我要张双人像"）引出含蓄的答应 | 洪源 p0097 | `lw-narrative` |

### 1.5 留白、节制与反煽情

| 作品 | 做法 | 页 | 方法归 |
|---|---|---|---|
| 《窗外的天气》 | ★ 副歌开头有三个急促叠音**本可放叠词**，作者故意回避，改用平淡语句——**「节制的笔法，更容易触动听者内在的情绪」** | 姚谦 p0003 | `lw-narrative` |
| 《窗外的天气》 | 结尾定格在"忘记关的窗，湿一地"——**「当主人公缺席，画面定格在一个空镜头时，才最煽情」** | 姚谦 p0003 | `lw-narrative` |
| 《旅行的意义》 | **开放式结局**：只丢出可能性，让听者想象 | 姚谦 p0001 | `lw-narrative` |
| 《飞》 | ★ **写失恋却没有一个伤心的字眼** | 姚谦 p0004 | `lw-narrative` |
| 《我只在乎你》 | ★ **中日文歌词里都没有提到"爱"，却把爱表露得深刻细腻** | 姚谦 p0003 | `lw-narrative` |
| 《陪伴者》 | 拿掉"承诺""正能量"这类字眼；**「没有画蛇添足的承诺讯息」** | 姚谦 p0003 | `lw-ai-tell-audit` |
| 《我是山泉》 | 「笑着走向死神」——张藜评为**「并未直接表白的含蓄美」** | 张藜 p0164 | `lw-narrative` |
| 《水蚀》 | 用水蚀比旧的习惯势力、礁石比被腐蚀的人——**「写得虽然含蓄，并不晦涩」** | 张藜 p0165 | `lw-narrative` |
| 洪源的四反 | **白、直、露、满**——词面之外要有潜台词 | 洪源 p0031–p0032 | `lw-narrative` |

### 1.6 句式、节奏与韵

| 案例 | 要点 | 页 | 方法归 |
|---|---|---|---|
| 《北京颂歌》 | ★ **音节"细微之变"**：5、5／2–4／4–5／4，**读起来铿锵顿挫、一气呵成** | 张藜 p0025（作品见 洪源 p0069–p0070） | `lw-mandarin` |
| 《都说他黑》 | 短促句式配急切坦率的性格；**硬改成七字句会同时破坏口语美与人物性格真实** | 张藜 p0120–p0121 | `lw-mandarin` |
| 《我心中盛开的雪莲花》 | 前四句**起承转合**：平稳起句 → 小突起 → 急转直下 → 次高潮；第二段改用短句与排比 | 张藜 p0119、p0121 | `lw-structure` |
| 段落结构对比 | 《都说他黑》是 **A A B**；《雪莲花》是 **A B A B** | 张藜 p0121 | `lw-structure` |
| 《不眠之夜》 | ★ **窄韵出新词**：选"也斜"辙，逼出明月、热血、皎洁、西斜、绿叶、迎接、蝴蝶等不常用的韵脚词 | 张藜 p0179 | `lw-mandarin`、`lw-rhyme` |
| 《我心中盛开的雪莲花》 | ★ **韵脚要和内容的色彩吻合**：雪莲是白的，就选"怀来"韵（覆盖、绽开、心怀、洁白） | 张藜 p0119 | `lw-rhyme` |
| 《边寨琴声》 | **"破四句"**：每段四句但长短错落，为音乐铺垫旋律与节奏的雏型 | 张藜 p0148 | `lw-structure` |
| 《口弦》 | 每句字数相等**但读起来节奏有变化**——因为题材本身富有天然节奏 | 张藜 p0149 | `lw-mandarin` |
| 《雨》 | 既有节奏规律又突破划一格式，作者称之为**联体节奏型**（揉散文体于格律之中） | 张藜 p0172–p0173 | `lw-structure` |
| 《公转自转》 | 旋律起伏不明显时靠**平仄与断句**救：把"我想"放到上一句旋律后段，让第一句旋律延伸到第二句才结束 | 姚谦 p0001 | `lw-mandarin` |
| 韵脚的自由 | ★ 姚谦：**先懂韵脚，再决定要不要守着韵脚；掌握韵脚而刻意避开不用，才是自由状态** | 姚谦 p0001 | `lw-rhyme` |
| 《从前慢》 | 每段三句、共四段，**字数与每句旋律都短，容易记忆和传唱** | 姚谦 p0003 | `lw-structure` |

### 1.8 改稿与删减

| 作品 | 改动 | 页 |
|---|---|---|
| 《绿海玫瑰》 | 只写景 → **写到心灵深处**（见 SKILL.md §3.7） | 张藜 p0040–p0041 |

| 《不要丢开我》 | 二十四句里**只有四句可用**；作者一连写了四稿、五稿、六稿直至十稿，最后把题目送给另一位作者写成 | 张藜 p0055–p0056 |

### 1.9 词与曲的交接

| 案例 | 要点 | 页 |
|---|---|---|
| 词作者的分寸 | ★ **「歌词作者的设想不能也不应该去代替作曲家的安排……设计得过于具体，我倒觉得会弄巧成拙」** | 张藜 p0115–p0116 |
| 作曲家要什么 | 曲作者要歌词**「简洁，音乐性强」**，且词里应含**音乐的大致设计**（节奏、韵律、腔调） | 张藜 p0129–p0130 |
| 给作曲家七样东西 | 表情符号、感情线索、律动形式、独特角度、可深化的形象、可体味的意境、**可自由飞翔的空间** | 洪源 p0022–p0023 |
| 不要逐字配调 | ★ **「那些逐字、逐句，亦步亦趋地为词写调子的人不是词作者真正的知音」** | 洪源 p0023 |
| 留空间 | ★ **「词不可铺得太满，句子不宜写得过长，要给音乐的反复、哼腔、拖腔、过门、前奏等等，留下足够的空间」** | 张藜 p0122 |
| 音区 | **「不可都安排在强音节上……忌讳高又高，强又强，致使演员难以演唱」** | 张藜 p0122 |
| 情绪统一 | 一个小段落里情绪要统一，否则曲作者**「象梦呓一样令人无法捕捉」** | 张藜 p0023 |
