⚠ **术语不统一是四本书之间最容易出事的地方**：
★ **刘小瑛把「紧音」叫「重音」、把「紧音化」叫「重音化」**（刘小瑛 p0123、p0177）——
**它和「重音（stress）」完全无关**，而韩语恰恰**没有**靠轻重区别词义的重音系统（郑政德 p0092）。
> ★★ **本 skill 一律用「紧音／紧音化」，不用「重音／重音化」**，以免与 `lw-english` 的重音混淆。

## 7. 方言标记速查（《韩国语概论》p0307–0311）

写角色歌、地方题材时用。**只挑可判错的**，风味词不列。

| 方言 | 标记 | 说明 |
|---|---|---|
| 庆尚道 | 终结词尾 **-노／-나**、**-고／-가** | ★ **按疑问句种类分化，是规则不是风味**：含 어디、언제、누가 等疑问词的特殊疑问句用 -노／-고；答 예／아니요 的一般疑问句用 -나／-가。中世韩国语的残留（p0309） |
| 咸镜道 | 终结词尾 **-지비**（相当于标准语 -지）；另有 -우다、-슴、-슴메、-소 一类 | p0307–0308 |
| 平安道 | 오마니（어머니）、에미네（아내／여자）、우딩（일부러） | 词汇标记（p0307） |
| 全罗道 | **-랑게／-당게／-옹게**，后面还可再接 로；께 可发成 게 | p0311 |

用了庆尚道口吻却把特殊疑问句写成 -나，懂的人一眼看出。
