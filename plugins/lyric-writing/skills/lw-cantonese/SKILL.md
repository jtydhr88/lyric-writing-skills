# 粤语填词的协音层（Cantonese）

> **这个 skill 回答一个问题：粤语这门语言，把填词的规则改成了什么样。**
> ★★ **答案不是"换一张韵表"。是三件事同时变了：约束从"风险"变成"硬约束"；
> 写作顺序从"词曲都可以先"变成"旋律先定"；检查从"查表"变成"先算类音阶，再唱一遍确认"。**

## 1. 协音：为什么它是硬约束

### 1.1 ★★ 九声、调值与声调唱名

**调值**是标音系统：**5 为最高音、1 为最低音**，用 1–5 表示声调由开始到结束的高低变化；
写两位时前者叫**调头**、后者叫**调尾**（黄志华《文字声律与粤语歌创作》p0010）。

| 声调 | 调值 | 唱名 | | 声调 | 调值 | 唱名 |
|---|---|---|---|---|---|---|
| 阴平（一声） | 55 | **三** | | 阳去（六声） | 22 | **二** |
| 阴上（二声） | 35 | 九 | | 阴入（七声） | 5 | 一 |
| 阴去（三声） | 33 | **四** | | 中入（八声） | 3 | 八 |
| 阳平（四声） | 11 | **〇** | | 阳入（九声） | 2 | 六 |
| 阳上（五声） | 23 | 五 | | | | |

调值见黄志华 p0010；唱名即 p0015 的「**三九四〇五二一八六**」，按一声到九声排。
★ **这九个字自己就读那个调**，念一遍就能自验。

⚠ **调值不是乐音**：「调值绝不应跟乐音挂钩、对应或绑定，因为字音是飘移不定的，**只有相对音高，没有绝对音高**」；
这 5 个数字**不可跟谱上的 1(do)…5(so) 混为一谈**（黄志华 p0010）。

三条附带事实（黄志华 p0010–p0016）：**①** 九声调值里**没有 4**；55、33、22、11 这类叫**横调**，粤语有四个，
「已趋近极限，**不可能再分割出第五个**」。**②** **第十声「上入声」**由阳入变调而来，调值 **35**（「飞碟」的「碟」、「警局」的「局」）。
**③** **上声字是「复音」字**：**从稍低处起音再攀升到调尾**，只因攀升太快才听起来像单音。

### 1.2 ★★ 四个类音阶：「〇二四三」

「粤语歌曲之协音与否，重点在于**字音的音高跟乐音的音高要有很好的配合**，因此必须把粤语的字音按高低分类」（黄志华 p0014）。
**归类原则**：「凡在乐音属同音反覆时，某一声调能与另一声调**互换地填进去且能很协音的唱出**，就可归为同一类别」（p0014）。
★ **等价而且更好记的一条：只看调尾**——「调尾决定了字音的最终高度」（p0014）。

| 类音阶 | 调尾 | 名称 | 包含的声调 | 唱一遍就能验 |
|---|---|---|---|---|
| **三** | 5 | **最高音字** | 阴平、阴上、阴入（＋第十声上入） | 「想当天披荆斩棘」 |
| **四** | 3 | **次高音字** | 阴去、阳上、中入 | 「发觉已有兴趣」 |
| **二** | 2 | **次低音字** | 阳去、阳入 | 「寂寞地望着树上」 |
| **〇** | 1 | **最低音字** | 阳平 | — |

名称见 p0015，各类所含声调与调尾、右列例句见 p0014——**同一类的字能互换填在同音反覆上**，整句用一个音唱下来都协。
★ **「〇二四三」是从低到高排的**；四个符号取自 §1.1 的唱名，每一类拿它里面一个声调的唱名来命名。

⚠⚠ **两条必须跟着一起记的限制**（黄志华 p0015、p0016）：
① 「四个入乐调类所构成的『字调旋律』与音乐旋律之间的对应**并没有唯一性**」——作者说这是「**很重要事实，值得用大号的字再重申一次**」；
★ **所以不存在"某个类音阶＝某个音"的对照表**，能对照的只有**相邻两字与音程**。
② 「**单音无协事**」——单单一个乐音，没有音高上的对照，与字音结合时「**其实几乎任何字都成立**」；
协音的最小单位是**两个乐音配两个字音**，不是一个字。

### 1.3 ★★ 真值表：相邻两字与音程的自然音距

**音距** ＝ 两个字音的距离，以**半音**为单位；**自然音距** ＝ 这两个字音与乐音结合时**最感自然谐协**的那个距离（黄志华 p0017）。

| 类音阶排列 | 自然音距（半音） | 音程 | 类型 |
|---|---|---|---|
| 〇〇、二二、四四、三三 | 0 | 同度 | **平移** |
| 二四／四二 | 内 1、外 3 | 小二度／小三度 | **级进** |
| 〇二／二〇、四三／三四 | 内 2、外 4 | 大二度／大三度 | **级进** |
| 〇四／四〇、二三／三二 | 5 | 纯四度 | **跳进** |
| 〇三／三〇 | 7 及以上 | 纯五度及以上 | **跳进** |

表见黄志华 p0017（「相邻二字与音程的最自然结合表」／「自然音距表」），三分法见 p0023。
★ **读法**：排列**由低类走向高类**（如「〇二」）＝**上行**；由高走向低（如「二〇」）＝**下行**。
一格给两个数时，大的叫**自然外音距**、小的叫**自然内音距**。
这张表的来路：「**观察了大量现成的粤语流行曲作品概括出来**，再经个人亲自验证」（p0017）。

**真值与近似值**（黄志华 p0018）：

- 自然音距**恰好等于**这两个乐音的音程 → 这对类音阶是它的**真值**；所以此表又叫**真值表**。差一点 → **近似值**
- ★ **真值定理**：一字填一音时，某类音阶排列是某旋律线的真值，**当且仅当**每两个相邻类音阶的自然音距与相应乐音的音程**完全相等**；只要有一对不等就只是近似值
- 一个音程可有**不止一个真值**：纯四度的真值有「〇四」和「二三」
- ⚠ **含六个半音的音程没有真值**，只能拿 5 半音的「二三」「〇四」或 7 半音的「〇三」去近似

> ★★ **最要紧的一句**：「在一字一音地填词的情况下，**存在很多目标旋律线……无法由类音阶之排列来构成其真值，只能构作出其近似值**」，
> 所以作者判断「**词有微拗是常态**！不过……也会存在一些曲调，**能全填以真值**」（黄志华 p0019）。
> ★ **后果**：目标不是"全曲零近似值"，是**把近似值放在它伤害最小的地方**（§3.1）。

### 1.4 ★★ 违了协音，不是"听着别扭"，是**变成另一个字**

三个有出处的实例（黄霑）：广告歌末句「**新鲜美国来**」，**高平音的「新」配了低音变成低平**，听起来像「**神仙美国来**」（p0070）；
「香港大学」并排谱曲，「**港**」**谱得不当会变成「降」**（p0102）；《教我如何不想他》「教」「我」谱得不合，唱成**「脚窝如何不想他」**（p0101）。

听众听到的不是"唱得怪"，是**「神仙」「降」「脚窝」**。没有"长音能救""重音能救""语境能救"这回事——
语境救的是词义，救不了**已经唱出来的那个音节本身就是别的字**。
★ **但"拗"有程度**：§1.3 的真值／近似值给的正是这个刻度。
**近似值＝微拗，仍可用**；**连近似值都算不上的排列＝倒字**，那才是上面三例。

⚠ **一条必须并排记住的相反估计**（黄霑 p0103）：流行歌曲音域通常**十度或十一度以内**，
不用半音**等于只有十余个音符可用**，而**常用字已有三千余**，「拿来填词**实际上不会太难**」。
★ **协音是硬约束，但不是死路**：难的不是"找到一个协音的字"，是**"找到既协音、又正好是你要说的那个意思的字"**（§2.3）。
同页给了最坏情况：「有时曲谱已定，**找不到合适的字来配，就要完全牺牲歌词，将就曲谱**。」

### 1.5 ★ 与普通话倒字的分界

| | 普通话倒字 | 粤语协音 |
|---|---|---|
| 声调数 | 4（＋轻声） | **9（＋第十声）**，归成**四个类音阶**（黄志华 p0010、p0014、p0015） |
| 违了的后果 | **风险**——长音、重音、语境都能救 | ★ **错字**——唱出来就是另一个字（黄霑 p0070、p0102） |
| 写作顺序 | 先词先曲都行 | ★ **旋律先定**（§2） |
| 判法 | 查调型表 ＋ 只查三类高危位置 | ★ **先算**：真值表、八分三／十六分三、六调法（§3.1、§3.3）；**唱是最后确认**（§3.5） |
| LYR-LINT 第 7 条 | 倒字率**报数** | ★ **协音违例 = 0**，这是门禁 |

⚠ **`lw-tone-check` 的检测器与它的五种改法，在粤语里一条都不适用**——它假设普通话四声，也假设"倒字是风险不是判决"。
★ **协音的毛病不会因为你熟练就消失**：黄霑 p0134 说这毛病**经两辈词人数十年努力仍难避免**，
黄志华 p0019 说**「词有微拗是常态」**。**它是每首歌都要过一遍的检查。**

## 2. ★★ 写作顺序反转

### 2.1 先曲后词是默认，先词后曲要付代价

**潘源良**：「广东歌的工序关系决定了 melody 之后才会填词，**填词人处于被动地位**」（《词家有道》p0094）；
**周礼茂**：填词是「**因应旋律填入文字，旋律先行**」（p0145）。
> ★ **这条直接改写 `lw-workflow` §1 的岔路口**：普通话那边"先曲后词 / 先词后曲"是个要答的问题；
> **粤语这边默认答案已经给定了，反过来要为"先词后曲"找理由。**

**先词后曲的代价**：**歌词的字限死旋律进行，一变动马上出现「倒字」**（黄霑 p0102）。
★ **黄志华给了量化版**：先写的歌词字音大跳频率天然接近**八分三**，据曲填的只有**十六分三**（§3.1 判据三），
**两者的类音阶频谱形态很不同，这很可能会使谱曲者谱出很不同的旋律形态**（黄志华 p0087）；
所以要像卢国沾那样，写词就「努力使**字音组合有韵律感**」，「**不致令旋律如诵经**」（《词家有道》p0046）。
★ **先词后曲也有一条余裕**：那时可以**多区分「九」（第二声）与「叁」，借用第二声升调、复音的特点**；
依曲填词时不必处处区分，那样「**将会大大减少了用字的选择与自由**」（黄志华 p0038）。

→ 代价怎么变小：九字诀「少跳进、多扣合、有曲式」与三个可数指标，见 [reference.md](reference.md) §14。

### 2.2 ★ 可操作的步骤：先定字调骨架，再选字

| 步 | 做什么 | 判据 |
|---|---|---|
| **1** | **反复听 demo**，先拿感觉与方向，还不要下笔 | 潘源良 p0104、p0109：**听歌的时间比填词的时间还要多** |
| **2** | **数每句的字数**，当成这首歌能写什么题材的前提 | `reference.md` §6.1 |
| **3** | ★ **把旋律逐句折成半音数**，用 §1.3 真值表写出这句的**类音阶骨架**（可能不止一套） | §3.1 判据一、二 |
| **4** | ★ **定"必须出现的那几个字"**（歌名、hook），看它们的类音阶**对不对得上骨架** | §2.3、§3.6 |
| **5** | 按骨架去找字，挑**意思对**的那个，**而不是**从想说的意思出发去找字 | 周礼茂 p0146：「往往是**旋律可以容纳一些字词**，而那些字词又能表达一种情绪或感觉，就可以了」 |
| **6** | **整段唱一遍**确认，唱不舒服的地方回第 3 步重算 | §3.5 |

★★ **第 5 步是整个反转的核心**：普通话写词是"想好要说什么 → 找字 → 检查倒字"；
**粤语是"先知道这个位置能放哪些类音阶 → 在里面找意思"。**
乔靖夫说得最直白：他填词**最大的困扰**是「想到 idea，但**想不到适合音调的字**放入歌内」（p0243）。

### 2.3 ★ 锁死风险：一个非写不可的词，可能根本进不去

**这是粤语独有的失败方式**，普通话那边只会"别扭"，这边是"写不了"：乔靖夫想写「我变做**海豚**」，
「海豚」的**音调不能填进去**，**妥协写成「变做鱼」**（《深蓝》，p0243）；潘源良为《皇后大道东》写过一稿**弃用**，
因为觉得「**皇**」**音韵不太配合**（p0108）。

> ★ **自检动作（越早做越省事）**：立意阶段定下的 `intent.anchor_object` 与歌名，
> **在动笔前先算它们的类音阶**，看跟该出现的那几个音的音程对不对得上。
> 对不上 → 先看 §3.6 值不值得硬拗；不值得 → **这一刻就换锚点**，不是改旋律。

⚠ **「海豚」→「鱼」不是偷懒，是这门语言的标准代价：接受一个更小的词，好过写一句唱出来是别的字的词。**

## 3. 实操：先算，后唱

> ★★ **顺序就是判据的顺序**：**§3.1 查表算 → §3.2 用弹性判能不能救 → §3.3 六调法试出该配哪个调 → §3.5 唱一遍确认。**
> **唱是最后一道确认，不再是唯一的办法。**

### 3.1 ★★ 三个可以算的判据
**判据一：查真值表（§1.3），逐对相邻字算一遍。**
把整句拆成**相邻两字一组**，每组比对"这两个字的自然音距"与"这两个乐音的半音数"：相等 → 真值；差一点 → 近似值；差得多 → 倒字。
例（黄志华 p0018）：旋律线 `d r r l`——`dr` 上行大二度可选「四三」，`rr` 同度可选「三三」，`rl` 下行纯四度可选「三二」，
于是填「四三三二」，**是真值**；同一个「四三三二」拿去填 `d r t t`，末尾 `rt` 下行小三度在表里找不到以「三」开头的选择，

★ 判据的表、例与全文在 [reference-calc.md](reference-calc.md)。

### 3.2 ★★ 自然音距的弹性：同一个字调能走多远
**自然音距不是死数，它能伸能缩**，但四个类音阶的伸缩本事不一样（黄志华 p0029）：
**〇**（低音组最低）与**三**（高音组最高）是**外张元**——「〇」可任意往低处沉，「三」可任意向高处飘升；
**二**、**四** 被夹在中间，是**内敛元**——把自然音距增大去配大一点的音程「好像不大可以」，**比较缺乏弹性**。

**一个可以自己做的实验**（黄志华 p0030）：「二三」自然音距 5 半音（字例「未通」），「二四」3 半音（字例「未痛」）。

★ 判据的表、例与全文在 [reference-calc.md](reference-calc.md)。

### 3.3 ★ 同声同韵六调试音法

**一个不需要看谱也能做的工具**（黄志华 p0038）：① 选定**一组从第一声到第六声都有音有字**的同声同韵字组，
例如「**大虎富特妇负**」「**渊怨怒表远愿**」「**分粉训焚奋份**」「**威委畏维伟胃**」；② 用这组字**试唱目标旋律**；
③ 唱得下去的那个调，就是这个位置该配的声调。

★ **为什么它比乱哼有用**：这组字**声母韵母全一样，只有声调不同**，唱出来的差别**只可能来自声调**，不会被字义、韵母开合干扰。
例：目标旋律 `m f' f' s, s. l t. d`，用「威委畏维伟胃」（都读 `wai`）试唱，可能唱出「胃伟委威，维伟畏」——
**再转写成声调，就知道这里要填第几声的字**（p0038）。
⚠ **它只覆盖第一到第六声**（舒声），**入声不在内**；那三个入声调要靠 §1.2 的类音阶归类去接。

### 3.4 ★ 八度填九声：不要以为某个调只能配某个音

**九个粤语声调可以无一遗漏地填进八度乐音之中**（黄志华 p0038、p0039）。作者做这件事**不是要建立"调—音"对照表**，
恰恰相反，是要打掉那个念头：坊间常见的对应是拿 `m r d s. d l. m d l.` 去配唱名「三九四〇五二一八六」（音域大六度），
但同一串唱名配 `d' t l d f m s f r` **也能唱得协音**（音域八度）——「『隐含的音高』**并不唯一**」（p0035、p0039）。

> ★★ **用处**：**一条旋律线一定有不止一种类音阶填法具良好的逼近程度**（p0039）。
> **所以"这个位置只能填某个字"多半是错觉**——先把候选排列全列出来（§3.1 判据二），再挑。

⚠ **三个要拆掉的误解**（黄志华 p0036）：①「四叁」配 `d m` 才算完美协音、配 `d r` 就不算——**两者都属真值**；
②一个乐句内「九」配的音不可比「叁」高——**没有这种禁忌**（《恭喜发财》「恭喜你」配 `l d' s.`，第二声的「喜」在最高位）；
③「九叁」只有配大二度才完美——**错**，平移下有三个半音的微调幅度。

### 3.5 ★★ 哼唱：最后一道确认

**算完了还要唱**——但唱现在的位置是**确认**，不是**替代**。
⚠ 「有时同一个人来唱，唱出的结果亦可能不是次次一样的；有时还可能觉得存在若干方案，难以判断哪个最好」（黄志华 p0038）。
**唱只能否掉明显不成立的方案，定不了"哪个最好"——那要靠 §3.1。**
**词人的经验说法并排看**：周礼茂「**填好我便会自己先唱，如连我也唱得不舒服就不可能把这份歌词交出来**」（《词家有道》p0145）；
周耀辉的第一条标准是「**我填过歌词后会否不自觉地唱出来**」（p0182）。**四家原话与两种唱法的分工见 `reference.md` §6.4。**

⚠ **用哪种唱法去验，本身有讲究**（黄霑 p0071）：粤剧粤曲要求把每个字的「首韵」「腹韵」「尾韵」全部清楚唱出，
而流行曲的咬字是**一下子首腹尾韵紧接着吐出来**。★ **验协音要按流行唱法（一口吐出）去唱**，
按粤曲那种拆开唱的方式去验，会验出一堆不存在的问题。
**自检**：每写完一句，**离开屏幕唱出来**。听见的是别的字 → 回 §3.1 重算这一句。

### 3.6 ★ 点题字可以拗：这是有先例的取舍

**全书里最反直觉、也最该记住的一条**：「**纵使是关于歌曲主题的重要点题字句，词人有时宁愿字音拗拗地或产生严重的倒字**」（黄志华 p0028）。
《狮子山下》的曲调只有 `re' do' ti la` 那几个音，「狮子山下」**勉强填得进，易拗成「狮子『牵』下」**，
但「拗拗地就拗拗地，**最重要是能在词意上顺利点题**」（p0028）。**另几个同类的例见 `reference.md` §6.5。**

**郑国江给的判据**（黄志华 p0027）：是否必须换字，标准是「**只要这个字不会导致错误的联想**」——
「歌曲之动人，在于歌者的情绪的表达，与音乐本身的配合，**个别的字发音是否正确反而是其次**」。

> ★★ **所以 §1.4 那条硬约束要这样收紧**：**倒成一个"也讲得通的别的意思"＝真事故**
> （本想写「睡人会获胜」，唱成「**衰人会获胜**」，新意思也成立，听众就不再联想而「径自抗拒这一歌词」）；
> **倒成一个明显不成词的音＝听众会自动跟着主题修正**，可以拗。
> **判据一句话：拗出来的那个东西，会不会被听懂成另一件事？**
>
> ★ 并排一条相反的经验说法：乔靖夫为「海豚」填不进而改写「鱼」（《词家有道》p0243，§2.3）——
> **换字与硬拗都是成立的选择**；黄志华给的是"什么时候可以硬拗"，词人访谈给的是"什么时候该认输换字"。
> 作者的收尾是：「**最好反而是在适当的地方加进点弹性**」（p0028）。

### 3.7 卡住的时候，先分清是哪一种卡

周博贤 p0309 把"写不下去"分成三个原因，**解法完全不同**：**文字上不能配合**（意思跟语气/风格不搭 → 回 `lw-song-intent`、§5 定语域）；
★ **音韵上不妥当**（协音问题 → 先回 §3.1 重算，再走 §3.8）；**字数不够**（→ `reference.md` §6.1，换说法或换题材）。
★ **先分类再动手**，否则会用改意思的办法去解协音问题。

### 3.8 三种改法，按代价从低到高

⓪ ★ **先试一逗一宇宙**：一个字不改，只重划句读，字音走向与乐音走向可在逗前逗后临时反转；内敛元的死结也能解（[reference.md](reference.md) §13）。下面三条都要改词，它排在最前。

① **换同义字**——代价最低，永远先试（乔靖夫「海豚」→「鱼」，《词家有道》p0243）；
② ★ **把双字词前后对调**——周耀辉 p0172：粤语歌「可以随时不用『的』字，或**将某个字眼的两个字前后对调**，听众接受度高」；
③ **打破常用语法**——周耀辉 p0172：粤语歌词**因必须夹音**，经常不得不打破常用语法，**容许较大的文字实验性**。

> ⚠⚠ **第 2 条有一条并排的反对意见**：黄霑 p0119 举《双星情歌》「**曳摇**共对轻舟飘」——
> 「曳摇」是**为配合旋律音调把「摇曳」倒过来**，他判为「**粤剧撰曲人急就章通病**」。
> ★ **两家不是矛盾**：**周耀辉说的是"这门语言给了你这个自由"；黄霑骂的是"你只是赶时间"。**
> **判据**：倒过来之后**读起来仍然是个能站住的说法** → 合法；只是为了凑音 → 就是黄霑说的那种。
> **自检**：把倒过来的那个词**单独念出来**问自己——这是个说法，还是一堆音？

### 3.9 ★ 第四条路：不换字，改那个音的唱法

《新奇洗衣粉》广告歌的「**粉**」字，作曲人梁乐音**用装饰音（Ornament）避免上声字「粉」唱成去声「粪」**——
**先将首韵提升一度，再拖下结束音**，「升」「拖」之间**要不着痕迹**（黄霑 p0071，例 4）。
**黄志华 p0015、p0036 把它讲成通则**：粤语歌唱的一个严格要求，是「**把升调处理为在相应的（即结束音高相同的）
非升调前加个低二度或低三度的装饰音**」，**这类处理一般不在乐谱上显示出来，却严格要求唱者自发施行**。
★ **所以上声字（第二、五声）本来就是这样唱的**，是常规不是特技（第二声调值 35，**调头短、调尾长**，p0036）。
★ **它动的是唱法，不是词**，执行归**库一** `mc-melody`／`mc-vocal-direction`；
**词这一侧只做一件事**：把这个字**标出来**注明"此处需装饰音处理"，写进 `checks.self_audit`。

### 3.10 改旋律，与交稿前的三条硬检查

**为一个字改旋律：默认不行**（§1.4）。**有先例的例外**：《3650 夜》原本只能填「三千五百五十夜」，后来**作曲人改了旋律**，
但周礼茂的评价是「**一般改曲就词的情况则不多**」（p0145）。**只有当那个字是全曲的题眼、且 §3.6 的硬拗与 §3.8 三条全试过之后**才提。

★ **交稿前的三条硬检查**，都是黄霑点名的、赶工造成的毛病（原因是「**借来的空间，借来的时间**」，p0144）：
① **强拍上误填虚字**（p0145）→ **把每句的强拍标出来**，看落在强拍上的是不是实词；
② **蕪杂**，多出一个可删的字（p0144，1974–1983 年间歌词最大的毛病）→ 每句逐字划掉念一遍，**划掉更顺的就删**；
③ **用错的动词**（p0144：「热血拼**抛**」——血能洒能流能喷能染，**却不能「抛」**）→ 把动词和宾语单独拎出来问：**这两个词真的能搭在一起吗**。
★ **这三条不需要才华，只需要多过一遍。** **写完还要"养"**：郑国江主张完成后**先放上一阵子再修饰**（《词家有道》p0008、p0017）；
粤语这边「养」还多一个用处——**放一阵子之后再唱一遍**，隔开时间才听得出哪个字其实唱成了别的字。

## 4. 粤语的韵与押韵（详见 `reference.md` §2–§4）

> ★ **`lw-mandarin` 的十三辙在这里整套作废**——辙是按普通话韵母归的类，**照十三辙押出来的韵在粤语里不一定押得上**。
> 通用原理去 `lw-rhyme`；本节只给粤语这一侧最要紧的四条。

1. ★★ **押韵 scheme 比"押不押"更要紧**（周博贤 p0306）：不一定全曲同韵，可能首段一个韵、中段一个韵，也可能隔句押，
   但要**设定一个 scheme，然后在重复的段落尽量跟随它**——**听众记住的是这个图案，不是某一个韵**。
   **自检**：把每段的韵按句标出来（如 A-B-A-B），看**重复段落的图案是否一致**。
   （一韵到底与换韵的两家主张、《啼笑姻缘》几乎每两句一转、「**转韵总比不叶韵好**」（黄霑 p0103），见 `reference.md` §4。）
2. ★★ **入声**：① **拖不长**，它是「**短促的调子**」（王力 p0021、p0022），粤语入声字「**一个最重要的特点是字音甚短促**」（黄志华 p0012）；
   ② **自成一类，不与平上去通押**——「**入声字更不能与其他各声通韵**」，「**入声韵的独立性很强**」（王力 p0071、p0122）；
   ③ 反查法：「凡**韵尾是 -n 或 -ng** 的字，**不会是入声字**」（王力 p0025）；
   ④ **入声字不易产生倒字**——短促易咬得结实，且**阳入声已是入声字中的最低音，无论怎样往下唱，字音仍不变**（黄志华 p0012）；
   ⑤ ⚠ **但入声韵有字荒**：十七个入声韵部里**只有「测刑贼」一个高中低音都比较多字可用**（黄志华 p0012）。
   > ★ **用法**：**一个收得急、拖不住的韵，天生适合短句、急收、句末不留余地的段落**。
   > **失效条件 / 自检**：**段落最后一个字要拖长、要唱响 → 不要用入声字**；把每段尾字**拉长唱三拍**，收不住的就是入声。
   > ★ **入声还分属三个类音阶**：阴入归「三」、中入归「四」、阳入归「二」（黄志华 p0014），所以它同时是**协音上的三个类别**。
3. ★ **罕见韵是可以用的**：张美贤填《冰点感觉》时**用了「哭」「足」等罕见韵脚，给人新鲜感觉**（p0194）；
   刘卓辉写《围城》时「**也故意用上《囍帖街》的韵脚**」（p0162）。**这对上 `lw-rhyme` 的 `surprise_notes` 与 LYR-LINT 第 9 条。**
4. **韵母的开合跟着歌手走**：乔靖夫 p0235 给**低沉类声线**的歌手写词时，**在押韵上刻意使用开口音**，令声线「**较开扬、较高亢**」；
   ⚠ 反方向——**闭口音（韵母收 m 或 p）听感黯淡、险沉、内敛**（黄志华 p0013），要的就是这个色调时才用。

## 5. 语域与年代味道（详见 `reference.md` §5、§7–§11）

**基本语域是"混"**——用广东话唱出来的书面语，即黄霑讲的「**三及第**」：**既有文言，也有接近国语口语的白话，
复有粤语方言**（黄霑 p0133；周耀辉 p0172），效果是「**通俗之余，避免了过份低俗**」（黄霑 p0134）。

1. **混得有规矩**——「佢」很少见，**多用「他」**；「冇」**多用「没」代替**（黄霑 p0134）
2. ⚠ **纯口语有掉进"草根"的风险**：刘卓辉说**全用广东话写容易变得市井低俗**（p0163）；郑国江的尺度是「**应是雅趣共赏才对**」（p0012）
3. ★ **语域要跟音乐走，不是跟你的偏好走**（周博贤 p0298「以乐定词」）：小调曲式的《祝英台》填现代书面语会「格格不入」，
   「**就像唐装配波鞋一样**」。**自检**：动笔前先问——**这段编曲要是给我一段话，它会用哪种语域说？**

**年代味道**：黄霑分六期（粤曲期 → 广告歌期 → 现代感期 1975–1979 → 奠基与新血之交 → 转型期 1984–1997 → 衰退期）。
**最要紧的一条**（黄霑 p0133）：**1975–1979 的"现代感"是三件事同时发生**——**哲理歌蔚然成风**、
**陈旧称谓（卿、哥、妹、郎、君）被「你」「我」取代**、**更加讲究歌词与旋律气氛的配合**。
★ **卡拉 OK 把音域从十一至十二度压到十度以内**（黄霑 p0155）——**音域越窄，每个音高位置上可用的类音阶越挤，协音越难**。
⚠ **今天写粤语词最大的陷阱不是协音，是"写得像林夕"**——四位词人从四个位置说了同一件事。
**自检**：把写好的词问一句——**"这份词换成林夕的名字，有人会怀疑吗？"**

## 7. 用完必过

- [ ] ★★ **每一句都算过类音阶骨架**：逐对相邻字比过真值表，标出真值与近似值；**句末长音填的是真值**（§1.3、§3.1）
- [ ] ★ **全词的跳进频率算过**，落在 0.21875 以下（§3.1 判据三）
- [ ] 过界的地方**查过圈环**：过一格且含外张元才留，三号环（二四）过界一律换；**「〇〇」连用处旋律是同音反覆**（§3.2）
- [ ] ★ **全词逐句唱过**（不是念过、看过），用的是**流行唱法**（一口吐出）（§3.5）
- [ ] ★ **歌名与 `anchor_object` 在动笔前就算过类音阶**（§2.3）
- [ ] **有意硬拗的点题字**，问过：拗出来会不会被听懂成另一件事（§3.6）
- [ ] 卡住处**分过类**（§3.7）；改协音时**先试换字**，倒词序的每一处**单独念过**（§3.8）
- [ ] 要装饰音才能救的字**标出来了**并交给库一（§3.9）；**没有为了一个字去改旋律**（§3.10）
- [ ] ★ **强拍上不是虚字**；没有可删的字；动词和宾语搭得上；写完**放过一阵子再唱一遍**（§3.10）
- [ ] 押韵的 **scheme 定了并在重复段落贯彻了**；**尾字要拖长的地方不是入声字**（§4）
- [ ] 语域是**混的**且**跟着编曲走**；问过"换成林夕的名字，有人会怀疑吗"（§5）
- [ ] ★ **`checks.computed` 里协音违例 = 0**；这一条不报数，是门禁（§1.5）
- [ ] ★ **没有用 `lw-tone-check` 或十三辙顶替本 skill**
