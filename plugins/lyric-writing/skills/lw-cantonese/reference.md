## 1. 「协音」这个说法有多老

黄霑 p0100 把它接回中国韵文传统：
中国古代的「曲子」与「长短句」（即宋代之「词」），是**先有曲谱，再按曲谱声调填上"协调"文字供人歌唱**。
杨缵《作词五要》的原话是「**自古作词能依句者少，依谱用字者百无一二**」；
**李清照讥笑苏东坡**的两句评语是「句读不葺之诗」和「**往往不协音律**」（黄霑 p0100）。

★ **用处**：这不是粤语流行曲发明的规矩，**是按谱填词这件事本身自带的规矩**。
**粤语只是把它从"讲究"变回了"必须"**，因为它的声调数目和辨义能力没有像普通话那样退化。
黄霑 p0100 同时判定**《啼笑姻缘》确立了「先曲后词」的传统**，即按谱倚声填词。

## 2. 入声字的情感色彩与它的字荒

**入声字的六类情感感觉**（黄志华 p0012，撮录自黄氏《保卫粤语》）：

| # | 感觉 | 字例 |
|---|---|---|
| 1 | 急疾感、突然感 | 急 疾 忽 然 速 霍 猝 扑 掣 插 拍 |
| 2 | 窒息感、逼迫感、抑哑感、憋结感 | 窒 塞 逼 迫 抑 哑 憋 结 屈 哭 泣 夹 窄 勒 侷 促 缩 斥 |
| 3 | 阻隔感、妨碍感、距离感 | 隔 绝 膜 脱 别 诀 灭 裂 析 折 拆 截 切 撇 障 隙 遏 |
| 4 | 收藏感、吸纳感、包围感、保护感、进入感 | 入 吸 汲 纳 合 含 匣 贴 缩 结 集 接 |
| 5 | 错愕感、惊异感、干涸感 | 错 愕 恶 吓 渴 涩 缩 乾 贼 惑 酷 烈 |
| 6 | 用力感、坚决感、不妥协感 | 力 厉 削 切 啄 踢 劈 割 剥 撼 夺 决 绝 结 实 划 拔 塞 插 直 |

★ 一般而言，**押入声韵宜于表现「激越」「谐谑」「急迫」等情感**（黄志华 p0012）。

**⚠ 入声韵有字荒**（黄志华 p0012）：同一韵部中**常常高中低音难见齐全**。
粤语入声韵共十七个韵部，除「割葛」字数太少不成韵部外，其余十六个里
**只有「测刑贼」一个韵部高中低音都比较多字可用**（其中高音字仍较少），
**缺中音字的韵部有六个**（曲目、出街、吸入、吉日、墨黑、识食），
**缺高音字的韵部有九个**（芍药、甲集、八达、摺叠、镬裂、脱月、国乐、活泼、劈石）。

★ **反过来的好处**：入声字**在字音与乐音结合时不易产生倒字**（黄志华 p0012），原因三条——
①音韵短促，歌者吐字时易咬得结实；②韵部高中低音每每不齐全，**总是拗音，往往有音无字**；
③**阳入声已是入声字之中的最低音，无论怎样往下唱，字音仍不变**。
实例：《月蚀》末句「悲痛看月蚀」填 `r d t. s. l.`，「月蚀」两个阳入字配一高一低，
**「月」即使压低音来唱仍不会拗音**（黄志华 p0012）。

## 3. 闭口音

**闭口音**指韵母以 **m** 或 **p** 结尾的字，听感「一般都倾向**黯淡、险沉、内敛**」（黄志华 p0013）。

**书里给的听感示例**：「三侠探剑心，兼及谈琴谈禅谈南音」「怎禁饮泣湿蓝襟！」（黄志华 p0013）。
**成篇的例**：杜甫《蜀相》（寻／森森／音／心／襟）；许冠杰《双星情歌》「泪残梦了烛影深／月明独照冷惊枕／醉拥孤衾悲不禁／夜半饮泣空帐独怀憾」——
**「是很能表现其中的黯淡、险沉、内敛的情感」**（黄志华 p0013）。

⚠ **适用范围**：作者自己划了一条界——「阳平声」「入声」「闭口音」这几样，
**「其实都颇不适合用于西方摇滚一类的音乐风格之演唱」**（黄志华 p0013）。

★ **阳平声的质地**：纯由阳平声构成的句子读起来「**极其低沉，如喃喃细语，如吟吟哦哦，如低回长叹**」（黄志华 p0011）。
★ **上声字的阻止感**：不管阴上阳上，**字音读起来都让人感到阻力**（黄志华 p0011）。

## 4. 押韵：一韵到底还是换韵

| | 主张 | 理由 |
|---|---|---|
| **黎彼得** | ★ **习惯一韵到底** | 「**容易记忆，歌手容易唱**」（《词家有道》p0036） |
| **卢永强** | ★ **不必死守** | 一韵到底「其实没有坏处。以发展的角度来说**可以宽松一点，不用太严谨地遵守这样严格的框框**」（p0083） |

卢永强的比喻值得记住：死守一韵到底像「煮**煲仔饭**，最严格的要求是必须要用炭炉及沙锅，
更要煮出饭香并带有焦味，这才是正宗的煲仔饭」（p0083）——
★ **意思是：它是一种讲究，不是一条规矩。**

**换韵有先例，而且有换得很密的先例**：

- 《财神到》是许冠杰要求「**不要一韵到底**」，因为中段加上时间关系要在新春时推出（黎彼得 p0031）
- 黄霑 p0103 记《啼笑姻缘》**用韵十分自由，几乎每两句一转**，并判定「**转韵总比不叶韵好**」

**周博贤 p0306 给了最可操作的中间路线——押韵 scheme**：

- 不一定全曲同韵，**可能是首段一个韵、中段一个韵、末段一个韵**
- 可能**隔句押韵**，但会**设定一个 scheme**（如正歌中第一、第三句一个韵，二、四句另一个韵）
- ★ **然后在重复的段落尽量跟随这个 scheme**

> ★ **这条比"押不押"更要紧**：**scheme 一旦定了就要贯彻，听众记住的是这个图案，不是某一个韵。**
> **自检动作**：把每段的韵按句标出来（如 A-B-A-B），看**重复段落的图案是否一致**。

**押韵在粤语歌里做的事**：**容易记**＋**更易唱**（周博贤 p0306；黄霑 p0103：叶韵令歌词唱出来**既易于记忆，也有声韵之美**）；
七十年代这一批粤语流行曲「**最多一韵到底**」，**双声叠韵、内韵仄韵经常出现**，以达致「音韵铿锵，有声情之美」（黄霑 p0143）。

## 5. 口语与书面语：三及第

### 5.1 基本语域是"混"

**粤语歌大部分是用广东话唱出来的书面语**，即黄霑讲过的「**三及第**」，**大量语言混合产生特别效果**（周耀辉 p0172）。

**黄霑 p0133 给的定义最清楚**：三及第是**既有「文言」，也有接近国语口语的「白话」，复有粤语方言**。
**效果**是令粤语流行曲「**通俗之余，避免了过份低俗**」（黄霑 p0134）。

**它有一条具体的用字规范**（黄霑 p0134）：
**太口语化而不合白话文文法的字眼不用**——「佢」很少见，**多用「他」**；「冇」**多用「没」代替**。

黄霑认为「**三及第**才是真正粤语流行曲」；**郑国江**认为这是当时粤语流行曲的**最大特色**，
谈粤语流行曲**绝不能忽略这一点**，否则「就没有了衔接点」（《词家有道》p0010）。
潘源良 p0099 说的是同一件事的结果：「将**书面语与日常粤语的表达混合**在一起发展，
所以成为一种**为大家所共同接受的粤语流行曲语言**」。

> ★ **实际含义**：**默认语域不是纯书面语，也不是纯口语，是两者混着，而且混得有规矩。**
> 一首粤语词通篇纯书面语会"不像粤语歌"；通篇纯口语会掉进 §5.3 的那个坑。

### 5.2 口语入词做什么用

| 作用 | 出处 |
|---|---|
| **听得懂，不用想** | 郑国江 p0010：口语入词的目的是「**听歌时候不需要思考直接就可以明白**」。例：《分分钟需要你》「咸鱼白菜也好好味」 |
| **贴近生活** | 向雪怀 p0061：「**口语并不等于俗语**」，「文雅的语言不一定人人明白，反而**口语就更贴近生活**」 |
| **某些体裁非它不可** | 郑国江 p0012：有些歌曲**不用口语化语句就不能产生效果**，如 **RAP 就必须口语化才有神韵** |
| **快歌比慢歌吃得住** | 黄伟文 p0210：口语入词的实验作品**多为快歌**（如杨千嬅《傻仔》）。但他同时说「**不能因为有旋律的限制便不去尝试**」 |

### 5.3 ★ 纯口语的风险：掉进"草根"

| 谁 | 说法 | 页 |
|---|---|---|
| **刘卓辉** | 推崇「**约定俗成**」：歌词**大部分遣词用语应为正常的中文，加入若干广东口语特色**；**全用广东话写容易变得市井低俗** | p0163 |
| **潘源良** | 纯粤语方言入词的作品不多，「**因为趣味很容易变成较草根**」 | p0099 |
| **郑国江** | 尺度的判据：「有时候**俗到一个地步但不要太过分**便可以了，未必是雅俗共赏，**应是雅趣共赏才对**」 | p0012 |

> ★ **三家给的是同一条线，只是措辞不同**：
> **口语是调味，不是主食**（刘卓辉）；**过了线就变草根**（潘源良）；**判据是"雅趣"不是"雅俗"**（郑国江）。

★ **这条线不是今人定的**：五十年代**粤剧过于典雅、粤语时代曲病于低俗**，
是**广告歌**用「**通俗而不庸俗**」的写法填补了两者之间的空间，
并**点醒了后来的粤语流行曲填词人**去「摸索出一条**雅俗共赏的中间路**」（黄霑 p0069–p0072）。

> **失效条件**：**刻意做全口语**是一条成立的路线——「**新广东歌运动**」的出发点就是重新思考
> 许冠杰的广东歌词为何生动，试图以**全广东口语入词**的方式逆流而上（黄伟文 p0209）。
> ★ **但那是一个要扛的立场，不是省事的写法。**

### 5.4 借音食字：手法与它的滥用

- **潘源良 p0088**：「**借音『食』字就是以出人意表的方式来写词**」；"以往很直接，现在是你想讲一样事物也会转弯"，**这是现今创作流行歌词跟过去的最大分野**。他 p0096 补：「其实**没有什么问题，在乎你如何使用**」
- ⚠ **向雪怀 p0070 的反对**：把这归为无形的"教坏"——**借音入字（食字）被滥用，造成文化混淆**，例如**四字词汇不应任意改动**

> ★ **并排保留，判据在"这个食字有没有第二层意思"**：
> 食出来的新意思能站住 → 潘源良那一边；只是音像、图个热闹 → 向雪怀骂的那一边。

### 5.5 语域要跟音乐走，不是跟你的偏好走

周博贤 p0298 的**以乐定词**：歌词风格**应依据音乐风格而定**，而非刻意选择口语或古文。
他的例子是《祝英台》——**小调曲式**，前一段旋律由**五声音阶 d、r、m、s、l** 组成，
**填入现代书面语会「格格不入」，填入古雅文字才能与歌曲配合**，否则「**就像唐装配波鞋一样**」。

周礼茂 p0149 的说法一致：是不是「中国风」**主要看编曲、音乐元素**；
音乐本身若已具诗情画意，**歌词就要配合相应风格**。

★ **自检动作**：动笔前先问——**这段编曲要是给我一段话，它会用哪种语域说？**
答不上来就再听几遍，别先决定"我要写得文一点"。

## 6. 字数、改旋律的先例、修与养

### 6.1 字数先于题材

| 情形 | 后果 | 页 |
|---|---|---|
| **字数多** | 能写下一个完整故事。《十个救火的少年》之所以写十个人，是因为「这首歌**有很多字数**……很少广东歌会有那么多字数」；字数多才想到用**寓言式故事写法** | 潘源良 p0103、p0104 |
| **字数少** | ★ **更难**。「写字数少的歌是较多字数更困难」——多字数可以把上一句没说完的意思**转移到下一句**，少字数（如《凭着爱》）**要配合 melody 的音韵且要有力度** | 潘源良 p0105 |
| **极端** | 黄霑《我爱你爱到发哂狂》整首只有**十多个字**且重复率高；《沧海一声笑》用了**八十二个字**。**两首都成立** | 《词家有道》p0064 |

★ **实际动作**：数完字数**再**定题材。潘源良说他**很少出现因句式长短被动而填不下去的情况**（p0094、p0109），
原因正是他**先跟着音乐走**，而不是先想定一个非写不可的主题。

### 6.2 什么时候可以要求改旋律

**有先例的例外**（周礼茂 p0145）：《3650 夜》原本只能填「三千五百五十夜」，
后来**作曲人改了旋律**，使之能唱成「三千六百五十夜」。
周礼茂自己的评价是：「**幸好作曲人愿意迁就，一般改曲就词的情况则不多**」。

**另一个方向的例外**（黄伟文 p0222）：林慕德在唱片公司做 A&R 时，
会**先捕捉一两句觉得有噱头的歌词，来铺排旋律**；《锡老婆会发达》到黄伟文手上时**已经有这一句**。

### 6.3 修，然后养

黄霑的填词五字诀是「**藏、运、化、新、修**」，**「修」是最后步骤**，
即把已写成的歌词修饰雕琢，才可以把歌词交出去（《词家有道》p0008、p0017）。

郑国江补了第六个字：「**养**」——「完成歌词后**可以先放上一阵子，再修饰一下**，效果的确可以更好」（p0017）。
他的比喻是种花：「处理了外型后还要施肥换泥」，「『养』可使花木**免于杂乱无章**」（p0008、p0017）。

★ **在粤语这边，「养」还多一个用处**：**放一阵子之后再唱一遍。**
第一遍写的时候耳朵已经被自己反复听的那段旋律带跑了，
隔开一段时间才听得出哪个字其实唱成了别的字。

### 6.4 词人们怎么哼唱自验

| 谁 | 做法 | 页 |
|---|---|---|
| **周礼茂** | 「**填好我便会自己先唱，如连我也唱得不舒服就不可能把这份歌词交出来**」 | p0145 |
| **周耀辉** | 满意与否的第一条标准：「**我填过歌词后会否不自觉地唱出来**，而唱的时候又觉得可以的」 | p0182 |
| **卢永强** | 歌手唱过一次后，哪里唱得不顺就「**替他改一些合适的字**」；「幸运的话**只改一个字**就完事。但有时又会**牵一发而动全身，改一个字变成改一段**」 | p0079 |
| **林夕** | 「最理想的状态当然是**唱得顺**，配合得如鱼得水」 | p0119 |

★ **两种唱不是一回事，都要做**：**周礼茂那种是"写的时候唱"**（边填边验，一句一句过）；
**周耀辉那种是"写完了忍不住唱"**（整首成不成立的总检）。
只做第二种，你会带着一整首的协音问题去做总检。

### 6.5 点题字宁可拗的几个先例

**核心判断**（黄志华 p0028）：「**纵使是关于歌曲主题的重要点题字句，词人有时宁愿字音拗拗地或产生严重的倒字**」。

| 歌 | 拗在哪（皆黄志华 p0028） |
|---|---|
| 《榴梿飘香》 | 凡填「榴梿」之处**都拗拗地音，易唱成「漏」榴**；为点题必须填入，「退而求其次，拗拗地也不去计较了」 |
| 《漓江曲》（卢国沾词） | 篇末点题「把爱心放在漓江上」，末三字唱来其实是「**利江相**」；仍是**情愿拗拗地** |
| 《爱和梦》（郑国江词） | hook line 的「雾愁地」，「雾」原本是「无」，**倒音倒成「雾」**；「结果是**宁要词意**」 |
| 《东方之珠》（郑国江词） | 最高潮处填「东方之珠」配 `r' d' t t`，**不是唱高手很易唱成「东放自住」** |
| 《唐吉诃德》 | 「唐吉诃德」连唱两次，第一次配 `l m m m`，第二次配 `l r r r`，第二次**拗拗地**，但「**应是绝对可以接受的弹性处理**」 |

★ **作者的收尾**：「**最好反而是在适当的地方加进点弹性，这才能使整首歌焕发出迷人的光彩**」（黄志华 p0028）。

## 7. 粤语流行曲的分期与各期词风

**分期按黄霑《粤语流行曲的发展与兴衰：香港流行音乐研究 1949–1997》。**
★ **用法**：当你要一种"年代味道"时，来这里查那个味道的具体成分是什么。
⚠ **不要当风格菜单直接点**，先读 §10 的失效条件。

| 期 | 词风与题材 | 出处 |
|---|---|---|
| **粤曲期**（五十年代） | 主流是**粤曲**，「处处粤曲声」；小市民闹剧的「**谐曲**」采用粤剧音乐里耳熟能详的「**小曲**」旋律，**填上生活化口语化歌词**，为后来的粤语时代曲打开风气 | 黄霑 p0040、p0043 |
| **广告歌期**（五十年代末起） | ★ **两极之间的中间路**：粤剧**过于典雅**、粤语时代曲**病于低俗**，广告歌用**通俗口语**填补这个空间，近似儿歌，紧贴生活；它**最注重吐字清楚**，直接影响了七十年代粤语流行曲歌手怎么「**咬字**」；它「通俗而不庸俗」的写法**点醒了后来的填词人** | 黄霑 p0069–p0072 |
| ★ **现代感期**（1975–1979） | **三条同时发生**：①题材更新，**除情歌外哲理歌蔚然成风**；②**陈旧称谓（卿、哥、妹、郎、君）不再采用，改用直接的「你」「我」**，现代人的「**自我**」常出现（《问我》「我笑住回答，讲一声，我系我」）；③**更加讲究歌词与旋律气氛的配合** | 黄霑 p0133 |
| **奠基与新血之交**（七十年代末—八十年代） | 奠基一辈：许冠杰、卢国沾、邓伟雄、郑国江、黄霑、叶绍德、黎彼得、苏翁；八十年代新一代：林振强、林敏骢、潘源良、潘伟源、向雪怀、卡龙、卢永强、韦然等，特点是**教育水平较佳、年轻、叛逆性强** | 黄霑 p0134 |
| **转型期**（1984–1997） | 社会**多元化**；**卡拉 OK** 与**偶像崇拜**主导消费；八十年代中**乐队潮**兴起，**题材与写法与主流不同，善于捕捉青年人孤寂感**（Raidas—林夕；达明一派—陈少琪、周耀辉；太极—因葵），但**旋律较生涩，歌词较多沙石** | 黄霑 p0152、p0153、p0157 |
| **衰退期**（九十年代后期） | **旋律音调繁促，用音之多之密「几乎令唱歌的人无法转一口气」**；失去优美旋律与和声，只剩「枪耳」（catchy）的花招，**歌曲寿命缩短** | 黄霑 p0174、p0175 |

## 8. 各期的两条数字背景

| 项 | 数 | 出处 |
|---|---|---|
| 卡拉 OK 之前的流行曲音域 | **十一至十二度** | 黄霑 p0155 |
| ★ 卡拉 OK 之后 | **收窄到十度以内**，黄霑评为「**未免有些矫枉过正**」 | 黄霑 p0155 |
| 黄霑用来算"填词难不难"的基数 | 音域十度或十一度、不用半音 ＝ **只有十余个音符可用**；对**三千余个常用字** | 黄霑 p0103 |
| 1977 年 CASH 成立时 | 作曲家不足 **10 人**，填词家约 **20 人** | 黄霑 p0155 |
| 1997 年 | 作曲家 **700 人**，词家 **377 人**，兼作曲作词者 **625 人** | 黄霑 p0155–p0156 |
| 后果 | 市场扩大导致供不应求，产品两极化：「**行货」多而精品少**，好坏差别巨大 | 黄霑 p0156 |

> ★ **对填词的直接后果**：**音域越窄，每个音高位置上可用的类音阶越挤，协音越难。**
> **十度的歌比十二度的歌难填**——这不是错觉。

## 9. 两个"运动"与它们的后果

**这一条是给"多写就会写得好"这个直觉的反例。**

| 事 | 内容 | 黄霑的判断 | 页 |
|---|---|---|---|
| **中文歌运动**（1988） | 商业二台宣布农历年后只播中文歌，并设「百份百原创日」 | 「**漂亮的，着实大收宣传之效**」，初期收听率跳升；但大气上少了英文歌，令听众耳朵「**跳不出港台歌曲范围**」，长远「**是自绝于高水准音乐**」 | p0163、p0164 |
| **原创歌运动**（1995） | 完全不播放改编歌曲 | ★ 好处是为本地创作人开拓空间；坏处是「**求过于供，水准就会低降**」，作品量多而水准下降「就会变成**恶性循环**」；判为「**颇有揠苗助长之嫌，后果接近『好心作坏事』**」，并称之为**由盛而衰的一个转捩点** | p0164 |

★ **对机器写词的含义**：**产量本身会伤害水准**——不是"写得多就写得好"，
是"写得多、每首都不推敲，就全是行货"（接 SKILL.md §3.10 的三条硬检查）。

**另一条同方向的**：黄霑 p0143 记香港这一代词人（郑国江、许冠杰、黎彼得、卢国沾、黄霑、邓伟雄等）
采用**「力求显浅」**的方法，理由是**歌词是写来唱、写来听的，必须显浅才入耳明白**。
他引李渔《闲情偶寄》：「诗文之词采贵典雅而贱粗鄙，宜蕴藉而忌分明；**词曲不然。话则本之街谈巷议，事则取其直说明言**。
凡读传奇而**有令人费解**……者，**便非绝妙好词**」（黄霑 p0143）。

## 10. ⚠ 写"年代味道"的失效条件

**不要把 §7 的表当风格菜单直接点。**

黄霑 p0119 骂许冠杰的情歌**用字陈旧、语法间有不通**——
二十世纪七十年代还用「卿」称对方，且「君」「你」混用，被评为「**架床叠屋**」，**全没有时代感**；
同页记下的原因是他出身**粤曲世家**，自小耳濡目染，**受影响而至不辨精粗**（黄霑 p0119）。

★ **教训**：**复古的用字，在它自己的年代就已经可能是毛病。**

> **要一种年代感，取的应该是那个时期的"题材与说话方式"（§7 中间那一列），不是它的旧称谓。**
> **自检动作**：把你为了"古味"而用的每一个称谓词单独拎出来，
> 问一句——**这个词是这首歌需要的，还是我在扮那个年代？**

## 11. ★★ 后林夕时代：今天写粤语词最大的陷阱

**不是协音，是"写得像林夕"。**

| 谁 | 说的 | 页 |
|---|---|---|
| **李峻一** | 「我们都**听得太多林夕的歌词**，很自然以为**好的歌词便要像新诗**。如果你的写法像黎彼得，便会被人认为低俗」——他认为这是自林夕兴起并**维持了「十多二十年」的定见** | p0248、p0254 |
| **周耀辉** | 新词人建立风格的时间太少，且**受林夕、黄伟文两大门派影响过大**，而「**个人风格还是要时间的**」 | p0182 |
| **林若宁** | 「我承认刚开始写词时，的确是**刻意模仿林夕**。很多时候难以避免会想到**林夕会如何用字，不用他的用法，这个字就不够好**」 | p0270 |
| **卢永强** | 「听到的都是**老面孔的作品，不是林夕就是黄伟文**」 | p0081 |

> ★★ **四个人从四个位置说了同一件事，所以这是本节最硬的一条。**
> **"写得有诗意、像新诗"在今天不是优点，是默认值**——而默认值正是 `lw-ai-tell-audit` 要抓的东西。
>
> **李峻一给的解药**（p0254）：黎彼得从前也写过「**很多通俗、直白但非常精彩的歌词**」，**这是另一条创作路子**。
> **自检动作**：把写好的词问一句——**"这份词换成林夕的名字，有人会怀疑吗？"**
> 不会有人怀疑 → 你写的是默认值，不是这首歌。

**还有一条结构上的"潜规则"要知道**（黄伟文 p0209）：
林振强和林夕巩固了粤语歌词的写法，确立了**结构上的限制**——
「**ABC 段的歌词必须不一样，副歌重复多于三遍后，便要写不同东西**」。
★ **这正是 LYR-LINT 第 10 条（副歌各遍文本不许完全相同）在粤语这边的本地依据。**

## 12. 政治与题材被迫改词的三个实例

**记在这里是因为它们演示了同一件事：改一个词，整句的重心就换了。**（黄霑 p0161）

| 歌 | 原稿 | 改后 |
|---|---|---|
| 许冠杰《加价热潮》 | 「黄面佬冇力，卒之入埋英国籍」 | 「我望能生对翼，即刻飞上月球揾过食」 |
| 彭健新《借来的土地》（郑国江词） | 「这是片暂借的**土地**生不了根」 | 「土地」改为「**美梦**」 |
| 林子祥《包青天》主题曲（黄霑词） | 「但愿我**中国**，天天见青天」 | 「中国」改为「**心里**」 |

★ **对填词的用处**：**这三处改动全都仍然协音**——
换的是同一类音阶的字，句子的音高走向没动，动的只有意思。
**这正是 SKILL.md §3.8 第 1 条「换同义字」的极端演示**：
**在协音的约束下，能换的字比你以为的多；换掉之后整句的指向可以完全不同。**

## 13. ★★ 一逗一宇宙：一个字不改的第 0 条改法

`SKILL.md` §3.8 的三种改法全都要改词，§3.9 要改唱法，§3.10 改旋律默认不行。
这一条**一个字都不用改，只是重新划分句读**，所以排在它们前面。黄志华把弹性协音技巧收成四项：
一逗一宇宙、同向原理、模拟原理、同音反覆原理，并明说最常用的是前两项（p0077）。

### 13.1 它是什么（p0064）

在一个乐句里设一个**句逗**，逗位可以由节拍形成，也可以由歌词的句读产生。
逗前逗后是两个互不干涉的小宇宙，**各自安排音字结合，不受另一边影响**。

★ **结果是字音走向与乐音走向可以在这一逗之间临时反转**。
《今天应该很高兴》「报章说▲今天的姿采」：逗前「说」低、逗后「今」高，字音前低后高；
乐音 fa→mi 前高后低。两个走向相反，唱来不拗（p0064）。

三条让它好用的性质（p0064、p0067）：

- **逗可以只是想象的**，实际演唱一气呵成，不必停顿
- **同一乐句可以设不止一处**，《变色龙》「面对」前后各一逗
- 逗位宜设在弱拍转强拍处，两边过渡最自然，**但实际相当随意**，四个十六分音符之内都设过逗，唱来并无不自然

### 13.2 代价：逗后字会微拗（p0065–0066）

逗后第一个字叫**逗后字**，一般容易产生微微拗音。机制是：
逗后字本身是高音字却要从较低处唱起（低唱高字），或本身是低音字却要从较高处唱起（高唱低字），
音头会先短暂唱成邻近的字再过渡回来，听感像一个很短的升调或降升调（p0065）。
横调字在下行旋律里作逗后字，常有唱成升调的倾向（p0065）。

**判据**：设逗之后看逗后字是"高唱高字"还是"低唱高字"。前者不拗（《哪像染病》的「染」就是高唱高字，p0066），
后者要么接受那一点微拗，要么换字。

### 13.3 ★ 它能解开内敛元的死结（p0064、p0066–0067）

`SKILL.md` §3.2 说内敛元几乎没有微调余地。一逗一宇宙是例外：
「哪像染病」类音阶「四二四二」全是内敛元，设逗之后「染病（四二）」**竟可以飙升一个六度大跳起唱**（p0066）。
《高山低谷》「二〇二四四」在「二〇二」与「四四」之间设一逗，两个内敛元就能配小六度（p0067）。

**用法**：卡在内敛元上、换字换不出来，先试设逗，再考虑 §3.8。

## 14. ★ 先词后曲：写什么样的词才谱得成

`SKILL.md` §2.1 说先词后曲要付代价，这一节是**怎么让代价变小**。
黄志华把它收成九字诀：**少跳进、多扣合、有曲式**（p0081）。做到了，写出来的就是"宜谱词"，
即使一字一音地谱，谱出来的旋律绝大部分也优美易记（p0085）。

### 14.1 少跳进（p0081）

**一个字句之内，字音跳进宜在三个以内**，口诀「一个孖，两个妙，三个顶极了」。
极端到无跳进更理想：《有谁共鸣》「〇二四三三三二，二四〇，二四二〇」只有同级与级进；
《仙乐飘飘处处闻》插曲「〇二二，二四四；二四四，四三三」同样无跳进。

**自检**：把一句的类音阶写出来，数跳进。这是三个指标里最容易数的。

### 14.2 多扣合：让一群句子的声律重出（p0081–0084）

| 手法 | 做什么 | 例 |
|---|---|---|
| 叠用字词 | 字词叠用，声律自然重出 | |
| 同字回互 | 同一个字在一两句内重复出现 | 「天若有情天亦老」 |
| 往复 | 辞意往而复返 | 「今人不见古时月，今月曾经照古人」 |
| 排比 | 连写多个句型相同、句意不等的句子，**重点在声律重出** | 「密匝匝蚁排兵，乱纷纷蜂酿蜜」 |
| 回文／镜射 | 类音阶有意排成回文，**一句里一小截回文也算** | 《分手总要在雨天》「三四二四三」 |
| 类音阶重出 | 相邻句子在相应位置重复类音阶，句头句腹句尾都行 | 《爱在深秋》两句同以「〇三，二四三四二三」起 |
| 层递 | 类音阶逐句递升或递降；只有四阶，递到边缘就只能折回 | 《Do Re Mi》递升、《酒干倘卖无》递降 |
| 顶真 | 上句句尾的类音阶（可不止一个）重现在下句句首，可连环 | 《桃花开》四个短句环环相扣 |

★ **两个可数的量**（p0084）：**扣合重数**（用了几种）与**扣合密度**（扣了几次）。
作者的判断是**重数一两重已理想，密度三四次已够**。不必堆。

### 14.3 有曲式（p0081）

写词时自己预设一个常见曲式（AABA、ABAC 之类），**旋律整段重复的地方，词的声律也要重出**。
单段反复的歌不算有曲式，做到少跳进、多扣合即可（p0085）。

### 14.4 四个层级（p0084–0085）

| 级 | 考量单位 | 条件 |
|---|---|---|
| 一 | 篇 | 设曲式 |
| 二 | 段 | 少跳进 ＋ 多扣合 |
| 三 | 句 | 少跳进 |
| 四 | | 自然零散的声律扣合 |

一至三级俱备才是标准的宜谱词。**先写词的目标至少定在第二级**。

另两条顺手记的（p0086）：粤曲小曲式的单段反复靠**定句**（基本不变）与**活句**（每段换）搭建；
先写词时**「三」音高字不怕连续重复**，「〇」偶尔也不怕。

## 15. ★ 基本弹性数值表与实测边界

`SKILL.md` §3.2 的圈环表是定性的。书里有定量的表（p0033–0034），单位是半音：

| 组合 | 基本弹性 |
|---|---|
| 〇〇、三三 | 3 |
| 二二、四四 | **2**，效果欠佳，慎用 |
| 二四 | 1–3 |
| 〇二、四三 | 2–5，偶可 1 |
| 〇四、二三 | 3 及以上；**3 时易拗，音程越大越差** |
| 〇三 | 5 及以上；5 时易微拗 |

作者自注：**这些只是"基本"，实践不应以此为限**，歌艺超群的歌手常能把超常配搭唱顺（p0033）。

★ **一处与 `SKILL.md` §3.2 不同，并排保留**：SKILL 说「二二、四四俱欠微调余地」，书里的表给的是 **2 个半音**（效果欠佳、慎用），不是零。

**实测边界**（p0050–0053），比表宽得多：

- 「〇二」外张实测到**大六度**（9 半音），「四三」到**八度**（12 半音）；作者估计「〇二」照理也能到八度，八度也不是极限（p0051–0052）
- 「〇四」「二三」含内敛元，属跳进却常配比自然音距小的音程，**可压缩到小二度**；「〇四」配小三度常见，配大二度未见（p0053）
- 旋律出现临时变化半音或小二度时，除真值「二四」，可用的近似值有「〇〇」「〇二」「四三」「三三」，**「四三」最常见**（p0053）
