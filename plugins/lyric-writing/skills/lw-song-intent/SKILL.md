# 动笔前必填（Song Intent）

**这是本库唯一的硬门禁：五项不填齐，不许写第一句词。**

## ★ 为什么设这个门禁

> **AI 写的词不是"用词不好"，是「没有人做过选择」。**

它会写出语法正确、押韵工整、意象丰富的四段词，
**而这四段可以属于任何一首歌**。那正是听出来是 AI 的原因。

**这五个问题就是强迫做选择的地方。**
后四项与库一 ARR-SPEC 的 `intent` 四项同构，也与剧本包的"这场戏的价值转折是什么"同构；
第一项是词独有的，因为**词有类型，曲没有**。

## 按任务读哪几节

| 任务 | 读 |
|---|---|
| 开一首新歌 | §1 → ★ 先答 §1.1 定类型 → 逐个答 §2–§5 |
| **写出来的每首都像在讲故事** | ★ §1.1、§1.2（**默认不是叙事型**） |
| 答不出来 | ★ §6（**答不出来本身就是信息**） |
| 分不清真答了还是填了 | ★ §7 |
| 词写完了觉得泛 | 回来重答一遍 |

## 边界

| 不归这里 | 归哪 |
|---|---|
| 意象怎么找、object writing 的练法 | `lw-imagery` |
| 视角、人称、时间锚点的**技术** | `lw-narrative`（★ 本 skill 只问"在哪个时刻"，它管"怎么写出那个时刻"） |
| 段落结构 | `lw-structure` |
| 主题的社会学/文学分析 | 不做 |

## 1. 五个问题

```yaml
intent:
  plot_type:        # ★ 先答。这首歌是哪一类：attitudinal / situational / narrative / expository
  one_thing:        # 这首歌只说一件事
  to_whom:          # 对谁说
  at_what_moment:   # 在哪个时刻说
  anchor_object:    # 一个贯穿全曲的、能拍照的物件
```

★ **五项之间不是并列的**：
**`plot_type` 定框架，`one_thing` 定内容，`to_whom` 定语气，`at_what_moment` 定时态与信息量，
`anchor_object` 定词汇。** 后四项都在第一项划定的框架里答，后三项又会反过来修改 `one_thing`。

### 1.1 ★ plot_type —— 先定这首歌是哪一类

Davis 把"选择情节类型"列为构建一首歌的**第一步**，排在决定情感、排列元素、得出结论之前（p0025）。
其余四问都是在一个类型里面答的，类型没定，四问的答案会各自漂。

**封闭集合，四选一**：

| `plot_type` | 它在做什么 | 有没有时间线 | 例 |
|---|---|---|---|
| **attitudinal 态度型** | 歌手表达对某人或某事的态度、情感 | 无 | ★ Davis：**大多数流行歌曲属于此类**（p0025） |
| **situational 情境型** | 给态度一个戏剧性框架，歌手在**对一个具体情境做反应** | 一个场景，不推进 | 告别；前科犯坐巴士回家（p0025） |
| **narrative 叙事型** | 真正的情节，线性、有始有终 | **有** | 回忆个人事件；讲认识的人；不带人称的"摄像机视角"（p0025–0026） |
| **expository 说理型** | 抓住一个道理反复说 | 无 | 中文传统里独立成类。★ 吴颂今：歌曲不擅长讲道理，**要把哲理变成理趣，再结合抒情**（p0049） |

★★ **默认不是叙事型。** Davis 说大多数流行歌曲是态度型或情境型（p0025、p0061），
吴颂今说歌词**多抒情少叙事**，即便有叙事也一笔带过（p0034）。
两个传统各自独立给出同一个结论。

**语料实测**（华语歌手榜前 100 位歌手的分层样本，按上面三问逐首判型）：国语非说唱 **态度型 64%、情境型 24%、说理型 8%、叙事型 5%**（n=487）；
说唱 67／22／3／8（n=100）；粤语态度型 69%（n=36，语料里的粤语歌就这么多，其余格太小）。两个传统的判断在华语语料上成立，叙事型是二十首里的一首。按年代不动：2000s、2010s、2020s 三格里态度型 60% 到 67%、叙事型 3% 到 6%（n=73／154／245）。
复核：抽 59 首让另一个模型盲判，判型一致 75%，自报把握高的 87%，分歧几乎全在态度型与情境型之间，叙事型与说理型的份额是稳的。

**为什么没选类型的词一定滑向叙事**：叙事是四类里唯一靠"接着讲下去"就能推进的，
其余三类都靠**再看一眼**推进。不知道自己在写哪一类，每一段都会想写点新的，
新的只能是新事件，于是所有歌都成了故事。

> 围绕一个标志物反复写的歌（一个动作、一个物件、一句口头禅）不是第五类。
> 那是态度型或情境型把结构全交给了 `anchor_object`（§5.3），物件在做段落该做的事。

### 1.2 ★ 它决定的一串下游选择

这张表是四问答完之后最容易漏掉的东西：**类型定了，人称、声音、重复预算就跟着定了**。

| | 人称 | 声音 | 重复预算 | 主要去哪个 skill |
|---|---|---|---|---|
| **态度型** | 一、二人称，强调 I 与 you（p0061） | 自言自语，或对某人说 | 副歌逐字重复；**主歌也可以只换角度不换事** | `lw-imagery`：五感词画从远到近排（p0027）。★ 四成态度型没有物件，锚是一句话（§5 开头） |
| **情境型** | 一、二人称（p0061） | ★ **必须锁定是在说还是在想**，不锁定词会糊（p0069） | 副歌逐字重复；主歌靠**再看一眼**推进 | `anchor_object` 承担结构（§5.3）；`lw-narrative` 留白 |
| **叙事型** | 第三人称特征性地用于故事歌（p0061）；第一人称回忆也可 | 讲给看不见的观众，本质是"想"（p0069） | ★ **副歌照样逐字重复**；只有主歌靠新事件推进 | `lw-narrative` 全部；`lw-structure` |
| **说理型** | 一、二人称 | 对某人说 | 副歌逐字重复；主歌换例子不换理 | 风险是宣导腔。回 §5 找物件，把理变成趣 |

语料里情境型有贯穿物件的占 86%，态度型只有 60%（n=115／313），物件承担结构这一条在情境型上是常态；叙事型第一人称只占 59%，比其他三类都低，但全样本第三人称只有 2%，"故事歌用第三人称"在华语里是少数做法。

**人称那一列是 `lw-narrative` §1.9 那张 WTS 表的选格依据**，表在那边，选哪一格在这里。

**重复预算那一列要看清楚**：四类的副歌都是逐字重复，这一点**不随类型变**；
类型只决定**主歌拿什么推进**。叙事型是唯一靠新事件推进主歌的，其余三类都靠再看一眼。
实测里两首叙事型商业歌反而是重复度最高的，因为它们把副歌整个交给了重复，主歌才腾得出手讲事。
所以没选类型的词出问题的链条是：不知道预算 → 副歌也不敢重复 → 每段都要新内容 → 只能靠新事件 → 词又长又全是故事。
预算怎么花，见 `lw-structure` §6.0。

### 1.3 怎么判，以及怎么知道判对了

**按序问三个问题**：

1. 这首歌**有没有时间线**（有始有终、事件在推进）？有 → **叙事型**
2. 没有时间线，但**有一个具体场景**，歌手在对它做反应？→ **情境型**
3. 既没时间线也没场景，只是**一个态度或一个道理反复说**？→ **态度型**或**说理型**

**情境型的失败模式**（Davis p0117）：听众说"像剧场歌曲"，意思是这首歌依赖一个剧本，
而剧本只在作者脑子里，词里没写。听众不知道这是在什么情况下发生的：台上？派对？日常？
**判据：情境能不能从词本身读出来。** 读不出来就回 §4，把时刻写进去。

**判"真答了"的判据**：说得出**第二段为什么不是第一段的复述**，而且答案要和类型一致。
叙事型答"发生了新事"；其余三类答"同一件事换了角度、加了重量"。
答成"发生了新事"而类型填的是态度型，两个里有一个是填的。

## 2. one_thing —— 这首歌只说一件事

### 2.1 规格

- **一句话**
- **不许两句**
- ★ **不许用"既…又…"、"一方面…另一方面…"**

Davis 把"简洁性"列为十大写作原则的第一条：**坚持一个想法，消除支线**，
一个精心做出来的歌词情节，**该能用一个短句概括**（p0086）。
她举的反例是一个学生写高中女孩暗恋同学，从二年级第一天写到八年级第二周，
把"情节的复杂"当成了"情节的发展"，全是无关细节；
修法不是删细节，是**只留男孩忽视她的那个时刻**，让副歌一句话去把余下的情绪担完（p0086）。
这条判据可以反过来用：**一句话概括不了，说明写的是过程，不是这件事本身。**

### 2.2 它抓的失败模式

**一首歌想说两件事 → 两件都说不透。**

这在 AI 写的词里特别常见，因为模型会把一个主题的所有相关面向都写进去：
爱情写成"思念 + 遗憾 + 释怀 + 祝福"，四段各一个，**听完不知道它在说什么**。

### 2.3 ★ 怎么判断它是不是真的一件事

**把它念出来。**

| 症状 | 判断 |
|---|---|
| 念出来像一句人话 | ✅ |
| 念出来像一个主题词（"爱情"、"成长"、"孤独"） | ❌ **那是题材不是立意** |
| 中间有个"和"字、逗号能拆成两半 | ❌ 两件事 |
| 说完之后想补一句"而且还…" | ❌ |

**反例 → 正例**：

| ❌ | ✅ |
|---|---|
| 关于失恋和成长 | **她搬走那天我才发现阳台是我的** |
| 表达对故乡的思念 | **我妈打电话只会问吃了没，我每次都说吃了** |
| 青春的美好与遗憾 | **毕业照上有个人我到现在都想不起名字** |

★ 注意正例的共同点：**它们都已经带着一个画面**，而且**都有一点不体面**。

## 3. to_whom —— 对谁说

### 3.1 规格

**一个具体对象。**
★ **"抒情"不是对象。"听众"也不是对象。**

Davis 把这个对象叫 **singee**：第二人称词里唯一被称为"你"的那个人、地方或物件，
在场的、不在场的、抽象的都算，**但选定之后要一路认它，不许再有别的"你"混进来把听众绕晕**（p0064）。
`to_whom` 填的就是这个 singee 的名字，填不出具体名字，说明这一项其实还没选定。

### 3.2 它抓的失败模式

**没有对象的词会自动滑向"面向所有人的正确话"**——
那种话必然抽象、必然安全、必然像 AI。

Davis 从反面把这条钉死：向一个泛指的"你"说教式的信息**必然显得说教**（p0065），
听众想要的是**偷听**一句对着某个具体人说的话，不是被一群人当面劝导。
所以就算这首歌确实想讲一个道理（说理型也一样），
把"你"换成"大家"解决不了说教感，**真正管用的办法是把对象缩小到一个具体的人，让听众去偷听**（p0066）。

### 3.3 可以的答案

| 类型 | 例 |
|---|---|
| **一个人** | 分手三年后的前任；十六岁的自己；从没见过的外公 |
| **一个不在场的人** | ★ 最好用——因为**可以说当面不敢说的话** |
| **一个物** | 那台卖掉的车；一间已经拆了的房子 |
| **一群特定的人** | 和我同一年毕业的那批人（**不是"年轻人"**） |
| **自己** | ——但要说清是**哪个时候的自己** |

### 3.4 ★ 它怎么改变词

**同一件事，对象不同，词就完全不同：**

| 对象 | 语气 |
|---|---|
| 对前任说 | 有账要算，会有具体细节 |
| 对现在的伴侣说 | 要小心，会有省略 |
| 对自己说 | 可以不讲道理 |
| 对一个不会听到的人说 | ★ **最自由**，可以直说 |

**自检动作**：把这首词想象成一条发出去的消息。**发给谁？**
答不上来，词就还没有对象。

## 4. at_what_moment —— 在哪个时刻说

### 4.1 规格

★ **一个时间点，不是一个时间段。**

| ❌ 时间段 | ✅ 时间点 |
|---|---|
| 分手以后 | **搬家那天，最后一趟下楼** |
| 那个夏天 | **知道成绩的那个下午三点** |
| 长大以后 | **第一次自己交房租的那个瞬间** |

### 4.2 它抓的失败模式

**没有时刻的词是"综述"**——它在总结一段经历，而不是在某个位置说话。
综述天然抽象，因为它要覆盖一整段时间。

Davis 的判据：**除非你告诉听众时间框架变了，否则一首歌默认只有一瞬间的感受**（p0076），
时间不能在段落间大幅前跳而不把这个跳跃写出来。
她给的反例是一首儿童歌，开头"妈妈今天把她带回家了"，到了最后一段却是哥哥推着婴儿车里的妹妹绕客厅转，
听众会卡在"新生儿怎么会坐车"，问题出在**作者忘了在四段之间交代已经过了三年**（p0076）。
反过来做对的例子是《Cat's in the Cradle》，每段开头都点一句"我儿子刚学会走路的那天"、
"我儿子刚满十岁的那天"，**年份的推进被明写出来了，所以听着不是综述**（p0076）。
`at_what_moment` 答成一个时间点，本质是先把默认值锁在"一瞬间"，
要跨时间就要像这样明写跳跃，否则词会自己滑成一段没有边界的回顾。

### 4.3 ★ 它决定信息量

**一个具体时刻限制了你能知道什么。**

例：立意是"我们会分手"，时刻是"还在一起的某个晚上"——
那么**词里不能出现"我们分手了"**，只能出现那个晚上能观察到的东西
（他洗碗的时间比平常长、微信回得慢了、空调调了他喜欢的温度）。

★★ **这个限制就是词变好的机制。**
它逼你用**征兆**代替**结论**，而征兆就是具体名词。

→ 这条直接连到 `lw-narrative` 的"留白"和 `lw-imagery` 的"具体名词"。

## 5. anchor_object —— 一个能拍照的物件

> ★ **锚也可以是一句话。** 语料里国语态度型 313 首有四成没有贯穿物件（66 首连意象系统都没有，59 首只有氛围没有物件）。这一组的做法很一致：
> 副歌是**一句直接对「你」说的话**（喊出分手、恳求别走、质问敢不敢、成对反问、口号、自责短句），主歌说的是**我现在什么状态**，不给画面；
> 破题句 41% 是独白、14% 是问句；口语占 82%（全部态度型只有 54%）；末遍副歌 52% 原样不动；第二段主歌常常逐字重复或只换个别词。
> 要写这种歌，`intent.anchor_object` 填「无」，把那句话填进 `anchor_phrase`，本节下面讲物件的判据就不适用；重复预算照 `lw-structure` §6.0。
> 判据反过来用：**如果你写出了物件和画面，而 brief 要的是"直接说"，那就是写成了情境型。**

### 5.1 规格

★ **能拍照。**

这是一个很狠的判据，它一次排除掉：
时光、远方、梦、自由、青春、思念、温柔、勇气、星辰大海……

| ❌ | ✅ |
|---|---|
| 回忆 | **一张压在玻璃板下的电影票** |
| 距离 | **手机里没删的那个地址** |
| 时间 | **他留下的那件洗到起球的卫衣** |
| 思念 | **总是多煮的那半碗饭** |

### 5.2 它抓的失败模式

**抽象名词堆砌**——AI 味最直接的来源。

Davis 把这条列为十大原则的"具体性"：听众要的是看、听、摸、闻、感觉，
kindness、sorrow、memories 这类抽象词**没有人味也没有形状，在听众记忆里留不下一点残影**（p0095）。
她的做法是把"影子"换成"实物"：`memories of you` 换成 `that velvet valentine`，
`jewelry you wore` 换成 `gold bangle bracelets`，她管这类能拍照的词叫 **Kodak words**（p0095）。
`anchor_object` 的"能拍照"判据就是 Kodak words 的另一种说法：
一句话如果换成抽象名词还成立，说明那不是物件，是贴了标签的情绪。

### 5.3 ★ 为什么要"贯穿全曲"

一个物件如果只出现一次，它是个细节；
**出现三次并且每次含义不同，它就是结构。**

**例（那件卫衣）**：
| 段落 | 它是什么 |
|---|---|
| 主歌 1 | 一件落下的衣服 |
| 副歌 | 还留着味道的东西 |
| 主歌 2 | **该还了却一直没还** |
| 尾 | **洗了，味道没了** |

★ **物件没变，它的意义随着歌推进——这就是"贯穿"。**
这也是词里最经济的结构手段：**不需要解释，只需要让它再出现一次。**

### 5.4 与库一的关系

★ `anchor_object` 常常也能提示编曲的 `arrangement_hook`——
**一个反复出现的物件，配一个反复出现的音响事件。**
（→ 库一 `mc-arrangement-arch` §7）

## 6. ★ 答不出来怎么办

**答不出来不是"还没想好"，是信息。**

| 哪一项答不出 | 说明 | 怎么办 |
|---|---|---|
| **one_thing** | 你还没想清楚要写什么 | ★ **不要开始写**。先去经历/回忆/观察 |
| **to_whom** | 你在写"一般意义上的某种情绪" | 挑一个具体的人，哪怕是虚构的 |
| **at_what_moment** | 你在写一段时间而不是一个位置 | 从那段时间里挑**最难受或最尴尬的那一分钟** |
| **anchor_object** | ★ **最常见** | 见 §6.1 |

### 6.1 找不到物件时

**回到那个时刻，问三个问题**：

1. **那时候你手里拿着什么？**
2. **那个房间里有什么是别人不会注意的？**
3. **有什么东西到现在还在你那儿？**

★ **第 3 个最管用**——还在你那儿的东西天然有"贯穿"的性质。

→ 更系统的方法见 `lw-imagery` 的 object writing。

## 7. ★ 怎么分辨"真答了"和"为了过检查填了"

**这是本 skill 最需要自律的地方。** 四条判据：

| # | 判据 |
|---|---|
| **1** | **`one_thing` 念出来是一句人话**，不是一个词组 |
| **2** | **`to_whom` 是一个你能想象出脸的人** |
| **3** | **`at_what_moment` 精确到分钟级**，而不是"某天" |
| **4** | ★ **`anchor_object` 能拍照，而且你能说出它的颜色、大小、新旧** |

★★ **第 4 条是照妖镜**：
填出来的物件说不出颜色和新旧，因为它是从"该有个物件"这个需求倒推出来的，
**不是从记忆里拿出来的**。

## 附：来源与状态

- **`plot_type` 的三分来自 Sheila Davis《Successful Lyric Writing》**（p0025–0026 定义、p0061 人称推导、p0069 情境歌的声音、p0117 剧场歌曲失败模式），
  **说理型这一支来自中文作词传统**（吴颂今 p0034、p0049）。两个传统独立收敛到同一组类型。
- **其余四个问题的框架是本库自己定的**，来自对「AI 直接写的词为什么一耳朵能听出来」的归纳；
  但每个问题的判据分别对得上 Davis 书里独立的一条原则：
  `one_thing` 对应"简洁性"（p0086），`to_whom` 对应 singee 的选定与不说教（p0064–0066），
  `at_what_moment` 对应"一瞬间的感受"与时间跳跃要明写（p0076），
  `anchor_object` 对应"具体性"与 Kodak words（p0095）。
- **与库一的对应**：ARR-SPEC 的 `intent` 也是四项
  （`one_thing` / `reference_pair` / `listener_situation` / `emotional_arc`），
  ★ 两者**不是同一套**：库一的第 2 项是"参照"，本库是"对谁说"——
  因为**词有说话人，曲没有**。
- ⚠ **§2.3、§3.3、§4.1、§5.1 的例子是本 skill 自拟的**，
  不是从底本抄的。
